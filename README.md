# Control Carbon Model

A research project for analyzing terrestrial ecosystem carbon-cycle models using control theory, impulse response functions (IRFs), transfer functions, quasi-static equilibria (QSEs), and source-sink diagnostics.

Initial goals:
- Develop model-agnostic state-space and transfer-function formulations for terrestrial carbon-cycle box models.
- Connect QSE disequilibrium to NEP/NEE source-sink behavior.
- Use IRFs and modal analysis to characterize carbon-cycle timescales and forcing-rate responses.
- Build adapters for process-based terrestrial ecosystem models, beginning with VISIT and later extending to additional models.
