# Part II. 中心となる研究課題

## 3. 主研究質問

以下を主要な研究質問とする。

**How can carbon storage capacity be interpreted as a time-varying reference in a nonlinear coupled carbon–hydraulic system, and under what conditions can actual carbon stocks track this reference?**

日本語：

「非線形な炭素・水理結合系において、carbon storage capacityを時間変化する参照状態としてどのように解釈でき、実際の炭素ストックはどのような条件でそれに追従できるのか。」

これを以下の問いに分ける。

### RQ1. Capacityの定義と厳密な誤差方程式

Luo型のcapacityを、平衡点の根としてではなく、現在の炭素入力と滞留時間から定義したとき、どのような厳密な動力学的関係が得られるか。

### RQ2. ISSと追従性能

Capacityの時間変化を入力と考えた場合、実ストックとの偏差にどのようなISS評価が成立するか。

### RQ3. 非線形フィードバックの影響

Capacity自身が葉炭素と葉水ポテンシャルに依存しているとき、形式的なISS評価を全結合系の安定性や追従性能へ、どの範囲まで拡張できるか。

### RQ4. 乾燥からの回復と水理閉鎖

VPDの変化速度、継続時間、初期状態によって生じる回復と水理閉鎖の違いを、capacity trackingとISSの観点からどこまで理解できるか。

### RQ5. より複雑な炭素循環系への一般化

平衡点を解析的に求められない場合でも、capacityと実ストックの偏差に基づく解析は成立するか。

# Part III. 数学的な基礎の再構築

## 4. モデルの整理

E4の全状態を

[
y=(\psi_x,\psi_l,C_L,C_W,C_R,C_S)^\top
]

とする。

炭素状態を

[
C=(C_L,C_W,C_R,C_S)^\top
]

とし、炭素方程式を

[
\dot C=MC+u(y)
]

の形に整理する。

ここで (M) は既存モデルの炭素移送・損失行列、(u(y)) は光合成による入力ベクトルである。

光合成には有理関数版

[
A(y)=p,h(\psi_l)\frac{qC_L}{1+qC_L}
]

を用いる。

E4の水理フィードバック、木部・葉の伝導度、蒸散需要、各パラメータは実装を確認して正確に記述すること。

**今回の解析では、原則としてモデル方程式と係数を変更しない。**

解析の都合による近似やモデル変更が必要になった場合は、別モデルとして明記し、その必要性を説明すること。

## 5. Luo型capacityを基本定義とする

Capacityを

[
\boxed{K(y)=-M^{-1}u(y)}
]

と定義する。

これは、現在の炭素入力と炭素移送・損失係数から求める**状態依存の瞬間capacity**である。

この定義では、capacityを求めるために水理・炭素の全系平衡を先に解く必要はない。

ここから

[
\boxed{\dot C=M(C-K)}
]

を導出する。

この恒等式が、今回の研究の出発点である。

以下の三つを厳密に区別すること。

* 現在の状態から定義される (K(y(t)))
* 炭素・水理の全系平衡 (y^*)
* 時間発展によって実際に到達する状態

全系平衡では (C^ *=K(y^* )) が成り立つが、その逆を無条件に主張してはならない。

特に、(C=K(y)) は炭素収支の停止条件であり、水理収支の停止までは保証しない。

## 6. Capacity tracking errorを導入する

誤差を

[
e=C-K(y)
]

と定義する。

通常の微分可能な領域では、

[
\boxed{\dot e=Me-\dot K}
]

を厳密に導出する。

ここでは、(\dot K) の状態依存性をまだ展開せず、まず外部入力

[
w(t)=-\dot K(t)
]

とみなした系

[
\dot e=Me+w
]

を考える。

この順序を守ること。

**まず入力付き線形誤差系について言えることを証明し、その後で非線形フィードバックへ戻る。**

# Part IV. ISS解析

## 7. 最初に証明すべき定理

(M) は定数のHurwitz行列である。

したがって、適切な行列ノルムに対して、定数 (c\ge1,\alpha>0) が存在し、

[
|e^{Mt}|\le ce^{-\alpha t}
]

が成立する。

これを利用して、

[
e(t)=e^{M(t-t_0)}e(t_0)
-\int_{t_0}^{t}e^{M(t-s)}\dot K(s),ds
]

を導き、

[
\boxed{
|e(t)|
\le
ce^{-\alpha(t-t_0)}|e(t_0)|
+
\frac{c}{\alpha}
|\dot K|_{L^\infty[t_0,t]}
}
]

を証明すること。

より鋭い評価やプール別の評価が得られる場合は、それも検討する。

この不等式を、**capacity tracking errorに対するISS評価**として位置づける。

ここから何が数学的に言えるかを丁寧に整理すること。

例えば、以下を検討する。

* (K) が一定の場合、(e) はゼロへ収束する。
* (\dot K) が有界なら、追従誤差には対応する上界がある。
* (\dot K) が十分に小さいとき、追従誤差を小さく抑えられる。
* (\dot K(t)\to0) のとき、どのような追加条件で (e(t)\to0) が言えるか。
* 一時的に大きな (\dot K) が生じた場合、その影響はどのように減衰するか。

定理の仮定、結論、証明を明示する。

### Lyapunov関数による別証明

(M) がHurwitzであることから、

[
M^\top P+PM=-Q
]

を満たす (P,Q\succ0) を利用し、

[
V(e)=e^\top Pe
]

によるISS-Lyapunov評価も導くこと。

必要に応じて二乗完成、Youngの不等式、比較定理を利用する。

変分定数法による証明とLyapunov証明の関係、得られる評価の違いを説明する。

# Part V. 最重要課題：外生入力ISSと全結合系を区別する

## 8. Capacityは外部から自由に与えられる入力ではない

E4では

[
K(y)=-M^{-1}u(y)
]

であり、capacityは (C_L) と (\psi_l) を通じて状態に依存する。

したがって、

[
\dot K= D_yK(y)\dot y
]

である。

上で得たISS評価は正しいが、 **(\dot K) は元の全系と独立した外部入力ではない** 。

次を明示的に区別すること。

**定理A：**
(\dot K) を外生入力として扱う誤差系のISS。

**定理B：**
元の非線形E4全結合系で、特定のVPD入力や水理変数の変化に対して成立する安定性・追従性・有界性。

定理Aが成立することだけを理由に、定理Bが成立すると主張してはならない。

この違いは今回の研究の中心的な数学的論点である。

## 9. (\dot K) の構造を解析する

今回の炭素入力は

[
u=bA(y)
]

の形なので、

[
K(y)=v_K A(y),\qquad v_K=-M^{-1}b
]

と表現できる。

ここで (v_K) は定数ベクトルである。

したがって、

[
\dot K=v_K\dot A
]

となる。

有理関数光合成を用い、

\frac{\partial A}{\partial C_L}\dot C_L
+
\frac{\partial A}{\partial\psi_l}\dot\psi_l
]

を各滑らかな領域で厳密に導くこと。

葉炭素方程式から

[
\dot C_L=-k_Le_L
]

が成立するため、(\dot K) の中に追従誤差自身が現れることを明示する。

その結果、

[
\dot e=Me-\dot K
]

を、追従誤差と水理変数による閉ループ系として再記述する。

特に、光合成の状態微分によって誤差系の有効な線形部分が変わることを調べる。

ここで次の問いに答えること。

1. 誤差系の収縮性を、どの領域で保証できるか。
2. 水理状態の変化を外生入力とみなす場合、どのISS評価が成立するか。
3. 全系のフィードバックを戻すと、どの追加条件が必要か。
4. それらの条件はE4の基準係数で成立するか。
5. 条件が成立しない領域では、実際にどのような現象が起きるか。

解析上扱いやすい場合には、(\psi_l) の変化率やVPDを入力とする局所ISS、incremental ISS、入力から出力へのゲイン、小ゲイン条件などを検討してよい。

ただし、これらを成立するものとして先に仮定しないこと。

# Part VI. 水理系との結合と乾燥応答

## 10. 固定VPDの平衡解析を補助的に利用する

従来の正平衡枝とJacobian解析は、ISSの妥当性を確認するための重要な比較材料である。

特に、

* VPD約2.44 kPaで正平衡が局所安定であること
* VPD約2.8453 kPaで複素固有値の虚軸横断が数値検出されること
* VPD約3.00 kPaで正平衡が局所不安定であること

を、capacity trackingの立場から再解釈する。

ただし、**正の全系平衡の局所不安定性と、外生入力 (\dot K) に対する誤差系のISSは矛盾しない**ことを数学的に説明する。

全系で不安定性を生むフィードバックが、誤差方程式にどのように現れるかを検討する。

この説明では単に「ISSだから安定」と書かず、何を入力とし、何を状態とした安定性なのかを毎回明記すること。

## 11. 時間変化するVPDをcapacity trackingとして理解する

既存の10日ランプと10年ランプの比較を利用する。

VPDの振幅、保持期間、初期状態など、比較する条件を正確に確認すること。

各軌道について、以下を計算・表示する。

* (C(t))：実際の炭素ストック
* (K(t))：瞬間capacity
* (e(t)=C(t)-K(t))：追従誤差
* (\dot K(t))：capacityの変化率
* (\psi_l(t))：葉水ポテンシャル
* (g_x(t),g_s(t))：水理伝導度
* VPDの時系列

必要に応じて、重み付き誤差ノルム、ISS上界、容量変化率の積分を求める。

以下を検証すること。

1. 速い乾燥ではcapacityがどのように動くか。
2. 実ストックとの偏差は、capacityの変化よりどれくらい遅れて現れるか。
3. 回復する軌道では、どの時点から追従誤差が縮小するか。
4. 木部閉鎖に入る軌道では、capacityとストックがどの順序で減衰するか。
5. 同じ最大VPDでも、時間スケジュールが異なると何が変わるか。

重要：

**固定VPDの局所不安定域を通過することだけを、不可逆的衰退の条件としない。**

また、10日と10年の二例だけから一般的なrate-induced tippingや限界速度を証明してはならない。

## 12. 水理閉鎖とISSの関係を整理する

既存の解析的結果として、基準E4で

[
\psi_l\le-3\ \mathrm{MPa}
]

に入った後、水理的に元の領域へ戻らず、

[
\dot C_L\le-0.35,C_L/\mathrm{year}

さらに、他の炭素プールおよびcapacityもゼロへ向かう。

この結果をISSの枠組みで再考すること。

特に、

* (K(t)\to0) と (C(t)\to0) はどのような関係にあるか。
* (e(t)=C(t)-K(t)\to0) は既存の定理とどう整合するか。
* Capacityがゼロへ向かう速度と、各炭素プールの減衰速度を比較できるか。
* 木部閉鎖後の (K(t)) が十分滑らかであり、ISS入力としてどのように扱えるか。
* (\dot K(t)\to0) だけでなく、減衰率や積分可能性について何が分かるか。

を検討する。

### 複数の時間尺度

水理変数、葉炭素、木部炭素、根炭素、土壌炭素の応答時間の違いを解析する。

ただし、各プールの単独損失時定数だけから全系の減衰速度を決めつけないこと。

# Part VII. 数学上の注意事項

## 13. 非滑らかな閉鎖境界

E4のコンダクタンスにはmax関数による区分的な定義がある。

したがって、すべての状態空間で通常のJacobianや微分可能性を仮定しないこと。

特に、

* (\psi_l=-3) MPa
* (\psi_l=-4) MPa
* (C_L=0)

について、関数の連続性、局所Lipschitz性、片側微分、軌道に沿った微分の成立範囲を確認すること。

必要ならcapacityの絶対連続性、ほとんど至る所の時間微分、積分形式のISS評価を使う。

閉鎖境界で古典的な偏微分が存在しないことと、時間積分による評価が使えないことを混同してはならない。

## 14. ゼロ炭素平衡の扱い

ゼロ炭素状態を、全系で孤立した唯一の平衡点として扱わない。

E4ではゼロ炭素平衡が連続集合を形成するため、その水理的自由度を考慮すること。

また、ISSによる (e\to0) から、水理状態も含む全系が特定のゼロ平衡点へ収束すると結論してはならない。

必要に応じて、集合への収束と、一点への収束を区別すること。

# Part IX. 複雑なモデルへの一般化

## 16. どの構造が一般化可能かを検討する

今回のE4では、

[
\dot C=MC+u(y)
]

という構造があるため、

[
K=-M^{-1}u,\qquad
\dot e=Me-\dot K
]

が利用できる。

この考え方を、より多くの炭素プールを持つモデルへ拡張するための条件を明らかにする。

例えば、

* (M) が一定でHurwitzの場合
* (M) が時間依存する場合
* (M) が状態依存する場合
* 入力が非線形かつ高次元の場合
* 水理・炭素間により複雑なフィードバックがある場合

を区別する。

特に (M=M(y,t)) となる場合は、固定行列で得られたISS評価を機械的に流用してはならない。

容量 (K=-M^{-1}u) の時間微分には、(M^{-1}) 自身の時間変化も現れる。

必要な一様安定性・逆行列の有界性・滑らかさを整理すること。

## 17. 平衡点の陽な表示に依存しない解析

E4の三次方程式を使わなくても成立する定理と、E4固有の定理を分離すること。

次を明確にする。

* ISS解析が成立するために平衡点の全列挙は必要か。
* どの情報は炭素移送行列の安定性だけから得られるか。
* どの情報は水理フィードバックの具体形に依存するか。
* 平衡点の個数や大域的な吸引域を知ることは、capacity trackingの評価にどこまで必要か。

より複雑なモデルに対しては、必要に応じて数値continuation、区間解析、数値的な安定性評価を検討する。

PINNやサロゲートモデルは、計算高速化・近似・データ同化の候補として扱う。

PINNが自動的に平衡点の個数やISSを証明するわけではないことを明記する。

まずはE4におけるISSの基礎を確立し、それから一般化の見通しを論じること。

# Part X. 執筆方針

## 18. 論文をISS中心に再構成する

新しい原稿を、既存原稿とは別に作成すること。

推奨仮題：

**Carbon Storage Capacity as a Time-Varying Reference in a Nonlinear Carbon–Hydraulic System: An Input-to-State Stability Perspective**

日本語仮題：

**非線形炭素・水理結合系における時間変動参照状態としての炭素貯留capacity：ISSに基づく再解釈**

推奨構成：

### 1. Introduction

従来のcarbon storage capacityの概念と、非線形な炭素・水理結合系へ適用する際の問題を述べる。

中心的問題は、「平衡点を求められるか」ではなく、「capacityは実際の炭素ストックにとって何を意味するか」である。

### 2. Model and instantaneous capacity

E4モデルを定義し、Luo型capacityと実炭素ストックの関係を導く。

### 3. Exact tracking-error dynamics

(e=C-K) を導入し、厳密な誤差方程式を示す。

### 4. ISS properties of the capacity-tracking error

変分定数法とLyapunov関数によりISS評価を証明する。

外生入力ISSと全結合系の安定性を区別する。

### 5. Effects of nonlinear carbon–hydraulic feedback

(\dot K) の状態依存性を展開し、閉ループ系の構造を解析する。

固定VPDの平衡解析を補助的な検証結果として用いる。

### 6. Drought transients and hydraulic closure

速い乾燥・遅い乾燥の軌道をcapacity trackingで比較し、水理閉鎖後の炭素減衰をISSと時間尺度の観点から理解する。

### 7. Discussion

従来の平衡中心のcapacity解釈とISSに基づくcapacity解釈を比較する。

「capacityが存在すること」「実ストックがcapacityを追従できること」「水理系が回復できること」の違いを論じる。

### 8. Generalization and limitations

状態依存の炭素移送行列、より高次元のモデル、数値的な解析、非滑らか性、生理学的仮定の限界を扱う。

### 9. Conclusion

非線形系におけるcapacityを、必ずしも全系の吸引平衡点ではなく、動的に変化する参照状態として解釈することの有効性と限界を整理する。

# Part XI. 証明水準と研究倫理

## 19. 主張を四つの段階に分類する

すべての主要な結論に、以下の分類を明示すること。

**[A] 解析的に証明した結果**

厳密な仮定、命題、証明があるもの。

**[B] 計算機支援によって厳密に検証した結果**

区間計算など、明示された数値誤差管理に基づくもの。

**[C] 数値実験から観察された結果**

特定の初期値、パラメータ、期間で観察されたもの。

**[D] 今後の仮説・研究上の見通し**

証明または十分な検証がまだないもの。

特に次の過大主張を禁止する。

* 誤差系のISSから全系の大域安定性を主張する。
* Capacityが一意であることから全系の収束を主張する。
* 正平衡の局所不安定性から必ず水理閉鎖すると主張する。
* 一つまたは二つのVPDランプから一般的な臨界速度を主張する。
* 数値積分の葉量下限を植物死亡と同一視する。
* モデルで定義された木部通水停止を、実植物の不可逆的な生理学的損傷の証明とみなす。
* 従来の指数関数版のHopf分岐の非線形型を、有理関数版へ流用する。
* ISS上界の成立を、その上界が実際の応答を精度よく予測することと混同する。

証明が失敗した場合は、失敗した理由と不足している仮定を記録すること。

# 最終的な研究上の目標

本研究で最終的に明らかにしたいのは、単に非線形系の平衡点がいくつあるかではない。

**状態依存のcarbon storage capacityを、実際の炭素ストックの動的な参照状態として扱ったとき、どのような条件下でその参照が有効であり、どのような水理フィードバックや環境変動によって追従が失われるのか。**

そのために、

[
\dot C=M(C-K),\qquad
\dot e=Me-\dot K
]

を出発点とし、ISSを基礎理論として採用する。

平衡解析・局所安定性・分岐解析・水理閉鎖は、この枠組みを深めるための補助的な解析として位置づけ直す。

**新しい論文は、「平衡点とその安定性に関する研究」ではなく、「非線形炭素・水理系におけるcapacity trackingと、その有効性・限界に関する研究」として構成すること。**

作業開始後、まずPhase 1〜3の数学的結果を提示し、**どこまで厳密に証明できたか、どこからが今後の仮説なのか**を明確にした中間報告を作成すること。その後に大規模な数値実験や論文の本格執筆へ進むこと。
