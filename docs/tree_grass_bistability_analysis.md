# 10プール候補の平衡消去と非存在条件

2026-09-30。[方程式](tree_grass_carbon_equations.md)に対する条件付き解析。
証明はこの文書の仮定に限る。VISIT全体の定理ではない。

## 1. 遮光だけでは正の安定群集が二つ生じない

f=0、気象固定、全損失率正、配分正、0<ρ≤1とする。
葉の平衡式は

\[
p_{TL}P_T\frac{1-e^{-a_T L_T}}{L_T}=d_{TL},\qquad
p_{GL}P_G e^{-\kappa L_T}\frac{1-e^{-a_G L_G}}{L_G}=d_{GL}.
\]

v_a(L)=(1−e^(−aL))/Lとすると、L>0で

\[
v_a'(L)=\frac{(1+aL)e^{-aL}-1}{L^2}<0,
\quad v_a(0+)=a,\quad v_a(\infty)=0.
\]

不等式はe^y>1+y（y>0）による。したがって木本の正の葉平衡が存在する必要十分条件は
r_T=p_TL P_T a_T−d_TL>0。そのとき一意なL_T*がある。
続いてr_G=p_GL P_G e^(−κL_T*)a_G−d_GL>0なら一意なL_G*>0があり、
それ以外には正の草本平衡はない。残りのプールは

\[
C_{ij}^*=p_{ij}\mu_i^*/d_{ij},\qquad
D_i^*=\mu_i^*/k_D,\qquad H_i^*=\rho\mu_i^*/k_H
\]

と一意に定まる。**正の10プール平衡は高々一つ**。
部位比一定の軌道近似を使った結論ではなく、元の10式の平衡を直接消去した結果。

### 局所安定性と侵入

正の葉平衡で葉方向の微分はp_iL P̃_i L_i* v_a'(L_i*)<0。
変数をL_T,L_G,S_T,R_T,S_G,R_G,D_T,D_G,H_T,H_Gの順に並べると、
全ヤコビアンは下三角。残りの対角は−d_iS,−d_iR,−k_D,−k_H。
よって正の平衡は10次元で局所漸近安定。

木本ゼロへの侵入指数はr_T、木本平衡上の草本ゼロへの侵入指数はr_G。
r_T>0,r_G>0なら対応する境界は侵入方向に不安定である。
r_i=0では非双曲的であり、上の指数安定性結論には含めない。
草本だけの平衡を作っても、木本への戻り作用がないためr_T>0の木本侵入を阻めない。
これは耐性やP_i,d_ijの差だけではこの対照の内部双安定性を作れないことを示す。

## 2. 遮光対照の条件付きno-R命題

有限時間[0,τ]の任意の有界な気象強制の後、係数を最終値で保持する。
全区間で生産は非負、損失率は有界かつ正、初期L_T,L_G>0。
最終値で上記r_T>0,r_G>0を満たすと仮定する。

**命題**：全10プールは同じ最終正平衡へ収束する。τによる別の安定群集への
恒久的遷移はない。過渡的な炭素損失や極端に長い回復は排除しない。

証明：有限時間では正の葉はゼロにならない。保持後、木本のスカラー葉式は
一意な正平衡の下で正、上で負なのでL_T→L_T*。
草本の有効P̃_G(t)=P_G exp(−κL_T(t))は正の最終値へ収束。
十分遅い時刻以降、これを最終値±εの定数で上下から挟める。
r_G>0を保つ小さなεの下で、上下のスカラー比較系はそれぞれ一意の
正平衡へ収束する。ε→0によりL_G→L_G*。
残りは収束入力を持つ安定線形フィルターの列なので各平衡へ収束する。□

これは任意の速度での最終到達先に関する命題。途中での枝の消失の有無を問わない
ほど強い条件付き結論だが、無期限強制、完全落葉イベント、種子流入、萌芽、
火災フィードバック、あるいは実際のCerradoへは拡張していない。

## 3. 火災を含む平衡：1変数の自己整合条件

気象を固定し、まずfを状態と独立なパラメータとして固定する。
q_ij(f)=d_ij+η_ij f、t_ij(f)=d_ij+(1−b_ij)η_ij fと置く。
両群の正の葉が存在する範囲では、前節と同じ単調性によって
L_T(f)、L_G(f)はそれぞれ一意。r_T(f)>0とr_G(f)>0を別々に確認する。

\[
C_{ij}(f)=\frac{p_{ij}\mu_i(f)}{q_{ij}(f)},\quad
D_i(f)=\frac{\mu_i(f)}{k_D+c_i f}
\sum_j\frac{p_{ij}t_{ij}(f)}{q_{ij}(f)},\quad
H_i(f)=\frac{\rho k_D}{k_H}D_i(f).
\]

元の火災系の正平衡は、以上に加えて

\[
\Phi(f):=\lambda h(\chi D_G(f))-f=0,\qquad 0\le f\le\lambda
\]

を満たすものと一対一に対応する。これが根数を調べるべき具体的な式である。
正平衡の存在区間外へ式を延長して根数を数えてはならない。

一つの連結区間上でΨ(f)=λh(χD_G(f))の微分が常に1未満なら、
Φは厳密減少し、その区間に正平衡は高々一つ。
閉区間I上でΨ(I)⊂Iかつsup_I|Ψ'|<1なら、縮小写像定理により
I内に一意の自己整合平衡が存在する。
複数の根が同一の滑らかな正平衡区間にあれば、Rolleの定理から
間にΨ'=1となる点が必要。**大きい相互作用は必要条件候補であり、十分条件ではない**。
異なる正平衡区間や境界平衡は別途数える必要がある。

木本損傷増加が草本を解放する効果と、草本自体の火災損傷・燃料消費が競合するため、
D_G'(f)の符号はこの一般形だけでは定まらない。関数を恣意的に曲げず、
台帳の観測制約からこの導関数の範囲を絞ることが次の解析課題になる。

## 4. 全10次元への接続：根の傾きだけでは安定性は決まらない

右辺をF(x,f)、eをD_G成分の単位ベクトル、v=∂F/∂f、
γ=λχh'(χD_G*)とする。fを固定したヤコビアンJ₀=∂F/∂xは、
上の正平衡で下三角化でき、Hurwitz。
しかし元の全系では

\[
J=J_0+\gamma v e^\top.
\]

平衡枝の微分はx'(f)=−J₀⁻¹vなので
Ψ'(f)=−γeᵀJ₀⁻¹v。
行列式補題から、sI−J₀が可逆な領域で

\[
\det(sI-J)=\det(sI-J_0)
[1-\gamma e^\top(sI-J_0)^{-1}v].
\]

s=0でΨ'=1は零固有値の条件になる。ただしΨ'<1だけから他の固有値を
左半平面に置くことはできない。燃料の遅れに由来する振動不安定性も未排除。
右半平面全体で|γeᵀ(sI−J₀)⁻¹v|<1ならJがHurwitzであることは十分条件となる。
二つの安定根とその間の根を得ても、サドルの安定多様体が吸引域境界を構成することや
他の吸引対象の不存在は追加の証明が必要。

この消去は**平衡の厳密な代数消去**。D_G(t)=D_G(f(t))という準定常動態を
導いたわけではない。草本リターを下流の安定フィルターとみなして消去すると、
戻りの作用そのものを失う。R-tippingへの縮約誤差評価は未実施。

## 5. 検算と到達点

[検算スクリプト](../examples/check_tree_grass_carbon.py)は、未較正の固定例で
行列/流量予算、境界非負性、capacity恒等式、遮光平衡残差と全ヤコビアン、
火災を外部固定した平衡消去とrank-oneヤコビアンを検査する。
火災固定例は内生火災の平衡・双安定性の証拠には用いない。
パラメータ探索や臨界速度の推定は行わない。

問い：10プールで何が証明でき、どこから追加根拠が必要か。
仮定：葉依存の飽和NPP、一定配分、非負の平均火災損失。
得た命題：遮光対照の正平衡一意性・全系安定性・最終正平衡へのno-R、
火災系の厳密な平衡自己整合式と全系安定性の検査式。
未証明：火災系の内部双安定性、吸引域、気象駆動R-tipping、現地較正。
次の一手：生態学的に許されるD_G'(f)、h'と気象応答を制約し、
単調性条件で非存在が決まるかを先に調べる。
