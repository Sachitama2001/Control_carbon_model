炭素–水・温度–降水・温度–NSCの独立縮約モデル、capacityの自己整合性解析、

## 次の解析を決める障害

1. 土壌含水率は枯死燃料含水率ではない。Tとθだけで火災率を定量化できるかを
   観測・過程モデルから判定し、必要なら補助状態を導入する。
2. D_Gには根由来炭素が含まれる。燃料となる地上細燃料を一定割合で代表できるかを確認する。
3. 葉だけに依存するNPPは完全落葉からの萌芽を表せない。根/貯蔵から葉への転流を
   追加する場合、その炭素の供給元と、上記no-R証明のどこが失われるかを明記する。
4. 以上を制約した後で、自己整合関数の傾きの上下界を評価する。
   双安定性が成立しないならその条件を成果とし、成立時だけ吸引域・速度解析へ進む。
