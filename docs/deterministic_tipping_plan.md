## 1. 現在の優先方針

This section records the 2026-09-08 implementation plan. It is no longer the
active priority; use it when the carbon-water work reaches its conditional
tipping stage.

- 状態空間表現へ外部強制を集約し、状態フィードバックの形と平衡枝の関係を調べる。
- 解析式と数値実験を並行させ、まず決定論的なB/R-tippingを対象とする。

- 確率項、SDE、N-tipping、雑音による早期警戒指標は導入しない。
- Kalman/EnKF/MPCも当面の実装対象外とする。
- 既存のIRF、接線モデル、native C照合は局所診断と原典検証として保持する。

## 2. 状態空間の符号と単位

研究モデルの基本形を次で固定する。

$$
\dot{\mathbf{x}}=A\,\Xi(t)\,K\,\mathbf{x}+B\,\boldsymbol{\mu}(t).
$$

| 記号 | 次元と意味 |
|---|---|
| $\mathbf{x}$ | $n$個の非負炭素在庫 |
| $A$ | $n\times n$、対角$-1$、非対角は非負の移送割合、列和は非正 |
| $K$ | 非負基礎速度$k_i$の対角行列、単位は時間の逆数 |
| $\Xi$ | 非負環境倍率$\xi_i$の対角行列、無次元 |
| $B$ | $n\times p$、非負の配分割合、各列の和は1 |
| $\boldsymbol{\mu}$ | $p$個の非負外部炭素流入、炭素量/時間 |

移送行列は供与プールが列、受領プールが行である。損失の符号は$A$に含めるので、
式の先頭へ追加のマイナスを置かない。系外流出は
$-\mathbf{1}^{\mathsf T}A\Xi K\mathbf{x}\geq0$であり、総炭素変化は
入力総和から系外流出を引いたものになる。これを無条件にNEPと呼ばない。

実装は `compartment_rhs`。倍率と速度は対角行列ではなくベクトルとして渡す。
呼出側で$A,\Xi,K,B,\mu$を状態にも依存させれば非線形化できるが、毎回の
非負性・列和条件は保持する。一般のODEは `ContinuousNonlinear` として扱い、
今回のAPIでは変動ドライバはスカラー1個、残りはモデルパラメータに固定する。
状態Jacobianは$J_x=\partial F/\partial x$と書き、移送行列$A$と区別する。

これらの連続時間ODEはVISITの日次逐次更新と同一ではない。VISIT土壌比較は
従来どおり離散日次代数で行う。

## 3. 最初の検証モデル

`SaturatingFeedback` は原典VISIT式ではない。機構と計算手法を検証するための
**仮説的な一槽炭素モデル**である。

$$
\dot x=P\frac{x^2}{H^2+x^2}-mx,\qquad P=mgH,
\quad m,H>0,\quad g\geq0.
$$

入力は在庫に依存するHill型飽和関数、損失は一次式であり、$x\geq0$なら両者とも
非負である。$x=0$では入力も消える。外部からの定着・移入がないという強い仮定を
含み、森林炭素動態全体や現実の不可逆性を表したものではない。単位は規格化した
炭素とモデル時間であり、Mg C ha^-1や日への較正はしていない。

フィードバックを外した対照は$\dot x=P-mx$である。このとき同じ外部強制でも
平衡は$x^*=P/m=gH$の一つだけで、固有値は常に$-m$である。
環境依存性が非線形でも、状態フィードバックなしで複数平衡が必ず現れるわけではない。

### 平衡枝と安定性

$g>2$では、非負平衡は三つある。

$$
x_0=0,\qquad x_\pm=\frac{H}{2}\left(g\pm\sqrt{g^2-4}\right).
$$

$$
F_x(0)=-m,\qquad
F_x(x_\pm)=m\frac{1-(x_\pm/H)^2}{1+(x_\pm/H)^2}.
$$

$x_0,x_+$は安定、$x_-$は不安定であり、正の半直線上で流域境界になる。
$g=2$で$x_-=x_+=H$となり、$F_x=0$、$F_{xx}=-m/H\ne0$、
$F_g=mH/2\ne0$なので通常のsaddle-node分岐である。
$g<2$では非負平衡はゼロだけとなる。

### B実験

$m=H=1$を固定し、$g:3\to1.5$を滑らかに変える。初期状態は$x_+(3)$とする。
$g=2$を通過すると高炭素平衡が消失し、最終強制を保持するとゼロへ収束する。
分岐通過後の遅れがあっても、原因は平衡枝の消失なのでB実験として扱う。
復路・ヒステリシスの系統実験は未実装である。

### R実験

$m=1,g=3$を固定し、$H:1\to10$を変える。**この設定では$P=mgH$も同時に変わる。**
外部入力座標は$H$の1個だが、最大入力と入力の在庫依存スケールを連動させる
仮説であり、単に気温や乾燥だけを変えた実験ではない。

全経路で三つの平衡が存在し、高炭素枝の固有値は一定の負値である。一方、
初期状態$x_+(1)=2.61803$は最終環境の不安定平衡$x_-(10)=3.81966$より低い。
急変の極限では状態が追従できず最終的に低炭素流域へ入り、十分遅い変化では
一様に安定な高炭素枝を追従する。これが速度依存移行を期待できる解析的根拠である。

数値実験では同じ経路を使い、最終環境を40モデル時間保持する。

| ランプ速度$r$ | 所要時間$1/r$ | 保持後の炭素 | 最終流域 |
|---|---|---|---|
| 0.01 | 100 | 26.18034 | 高炭素 |
| 10 | 0.1 | ゼロ近傍 | 低炭素 |

判定は既知の最終自律系の流域に基づく。大きな追従誤差や一時的な炭素放出を
それだけでR-tippingとは呼ばない。流域判定と平衡までの距離・残差は別々に返す。
有限保持で未緩和の状態を平衡と報告しない。最終環境が分岐点なら判定を保留する。

## 4. 強制と数値計算

`SmoothRamp` は$s=\mathrm{clip}(r(t-t_0),0,1)$として
$\lambda(t)=\lambda_0+(\lambda_1-\lambda_0)s^2(3-2s)$を使う。
前後は完全に固定値、接続は$C^1$である。$r$は時間の逆数であり、気象量/時間ではない。
最大ドライバ速度は$1.5|\lambda_1-\lambda_0|r$となる。

- 積分はSciPy DOP853。標準 `rtol=1e-9, atol=1e-11`。
- ランプと保持を分割し、短い強制を内部積分ステップが飛び越えないよう制限する。
- 精密化は `rtol=1e-11, atol=1e-13` と内部最大刻み幅の半減で比較する。
- B、低速R、高速Rの最大軌道差は今回の実行でそれぞれ約
  `2.94e-13, 4.97e-14, 2.99e-12`（規格化炭素単位）。
- これは同じODEの数値精密化による差であり、生態系モデル誤差や観測誤差ではない。
- 高速Rでは保持時間80でも低炭素判定が変わらないことをテストする。
- 局所平衡ソルバは残差、成功フラグ、Jacobian、固有値、条件数を返すが、
  初期推測1個から全平衡枝を発見したとは主張しない。全枝列挙は今回の解析式を使う。
- 速度走査は19点の比較であり、臨界速度の精密推定ではない。

## 5. 気象変数を絞った原典対応の対照

図AではTKYに対応するclass 4の土壌パラメータを使い、上層土壌温度だけを
0-25 Cへ変えて凍結環境下の固定点を解く。これは時間軌道ではなく平衡曲線である。
温度を時変させたnative/Python/接線比較は既存の温度pulseスクリプトに残している。

| 項目 | この実験での扱い |
|---|---|
| 上層土壌温度 | 0-25 C、唯一の変動環境座標 |
| 深層土壌温度 | 8 Cに固定 |
| 上層・下層水量 | 50、100 mmに固定 |
| 上層・全層aperture | 0.8、0.9に固定 |
| field capacity | 120、300 mmに固定 |
| litter入力 | 6経路それぞれ0.01 Mg C ha^-1 day^-1に固定 |
| 植物・水文・放射・CO2・VPD | この土壌サブシステムでは未結合 |

固定値は合成試験条件であり、観測TKYや自己整合的な水文平衡ではない。
特に水量とapertureを独立に指定する既存fixtureを使っている。
温度応答は `decomposition.c::frl/frh`、土壌収支は `soil_proc.c::f_cycle_soil` に基づく。
commitは `3285bd8e131a932e338b59892751648fd9edcc7b`。
パラメータと補助workbookのSHAは生成manifestへ保存する。

この対照では各温度で安定な一意の固定点が得られる。温度に対する炭素量の
非線形な変化と、複数平衡・tippingを区別するための対照であり、
VISIT全体にtippingが存在しないという証明ではない。

## 6. 再現方法と図の読み方

リポジトリルートから実行する。

```bash
python -m pip install -e '.[dev,analysis]'
pytest -q tests/test_nonlinear.py tests/test_tipping.py
PYTHONPATH=src python examples/plot_deterministic_tipping.py
```

出力は `artifacts/deterministic_tipping.png` と、同名の `.npz`、`.json`。
配列には時間・状態・強制・平衡枝・速度走査を、JSONには固定パラメータ、
単位の説明、保持時間、許容誤差、刻み幅、原典情報、結果を保存する。

| パネル | 比較内容 |
|---|---|
| A | VISIT日次土壌固定点の温度依存。10 Cの炭素量で規格化 |
| B | 仮説モデルの全解析枝とフィードバックなしの一意平衡 |
| C | 高炭素枝が消えるB実験、強制、数値軌道と移動QSE |
| D | 同じ$H$経路で低速・高速の状態軌道。星は共通初期状態、四角は保持後 |
| E | ランプ直後と保持後を区別した速度走査 |
| F | 許容誤差と刻み幅を厳しくした際の最大軌道差 |

Dの横軸は時間ではなく外部ドライバである。$H=10$の縦の軌道部分は最終固定環境下の
緩和を表す。自律系の相平面やIRFではない。線形IRFを大振幅tippingの予測としては使わない。

## 7. 次の実装段階

| 段階 | 状態 | 完了条件・次の対象 |
|---|---|---|
| D0: 数学契約 | 実装済み | 符号、単位、区画収支、単一ドライバ、非線形積分・平衡診断 |
| D1: 複数平衡 | 初回実装済み | Hill型入力の全枝、安定性、fold、フィードバックなしの対照 |
| D2: 決定論的速度実験 | 初回実装済み | 共通経路での流域移行、保持、精密化。臨界速度探索と復路実験は後続 |
| D3: 気象の限定接続 | 土壌温度対照済み | 次は温度の植物側経路を一つ選び、他の気象を固定して原典式と結ぶ |
| D4: 原典に基づく機構比較 | 次の重点 | 葉量-LAI-光合成、呼吸、配分のうち一つの閉じたフィードバックを比較 |
| D5: 低次元から拡張 | 未着手 | 植物-土壌結合、必要に応じNSC/水文状態、汎用continuation・流域探索 |

D4では単純な飽和入力、強い低密度促進、状態依存配分などを一つずつ比較する。
原典のままでは複数平衡が生じない場合も結果として残す。今回のHill指数2を
VISITの光合成式へ無根拠に移植しない。各式に「原典再現」「滑らかな近似」
「仮説的追加フィードバック」の区分を付ける。

温度だけで水分機構を説明できない段階になったら、次に水分ストレスを1座標追加する。
ERA5体積水分をVISIT内部bucket水量へ直接代入しない。気象データ取得は公式CDSのみを使う。
確率的な機構はこの段階表には含めず、別途合意してから検討する。
