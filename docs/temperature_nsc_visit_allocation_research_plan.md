# 温度–NSC実験計画：NSC依存枯死を除き、VISITの目標葉量・配分を調べる

作成：2026-09-23。状態：**計画のみ。新しいモデルの実装・実験は未実施。**

## 1. 目的と今回の変更範囲

前回の8状態モデルを維持し、NSC不足による枯死を外す。
VISITの目標葉量を導入したとき、どの過程が平衡の個数・安定性・吸引域を変えるかを調べる。
多安定性が確認された場合のみ、温度変化率による吸引域間の遷移を検証する。
「多安定性が生じそう」という順位は探索仮説であり、発生を保証しない。

前回の知見（`temperature_nsc_first_results.md`）を出発点とする。

- 単純な一定目標葉量モデルではR-tippingを検出しなかった。
- 支持組織依存の目標葉量では多安定性が生じたが、NSC枯死を除いても残った。
- したがって、枯死則ではなく、成長・維持・配分の構成式をまず調べる。
- fold近傍の長い過渡を別の吸引状態と誤認しない。

状態は `x=(C_L,C_S,C_R,C_O,N_L,N_S,N_R,N_O)`、単位はMg C ha⁻¹、時間はday。
N_L,N_S,N_Rは植物NSC、N_Oは土壌易分解性炭素であり、植物濃度には含めない。
温度のみを操作し、水分・光・日長・CO₂・栄養条件は固定する。
TKYの落葉広葉樹をパラメータ参照先とし、C3の**樹木**を対象にする。C3/C4草本は追加しない。

NSC依存枯死は `mu_NSC=0` とし、Hill指数・濃度閾値・枯死上限の走査をやめる。
一定の背景損失mu0と器官turnoverは残す。NSC不足を構造炭素の追加死亡・負の成長へ
読み替えて再導入しない。呼吸不足は診断量のまま保存する。
8状態は前回どおりで、被覆率、窒素、水、順化、個体数、フェノロジー記憶は追加しない。

2026-09-23の確認時にソース作業ツリーの変更はない。

元の処理は、概略、展葉→落葉→LAI更新→GPP→維持呼吸→EPP→配分→成長呼吸→

であり、ネイティブVISITの連続時間での厳密再現とは呼ばない。
個々の代数式の転記、日次写像、ODE適応、解析用近似を台帳で分離する。

## 3. 目標葉量の定義

### 3.1 葉炭素とLAI

ソースの係数をそのまま使うと

\[
 L=\gamma C_L,\quad \gamma=\frac{2.2\,\mathrm{SLA}}{200},\qquad
 C_L^*=\frac{200}{2.2\,\mathrm{SLA}}L^*.
\]

Lは片面LAI [m² m⁻²]、SLAは[cm² g dry matter⁻¹]。
出典：`ecophysiology.c` 117–122、`allocation.c` 37、`structure.h` 395。
`definition.h` 27の`dmTc=2.2`は、コメントの名称だけでなく、この実際の使用方向で解釈する。
葉炭素をNSC込みのC_L+N_Lに置き換えない。

### 3.2 目標LAIのソース代数

P=psat、q=lue、I=ppfd_t、k=eK、h=daylen、a=arと置く。
`f_opt_lai`が計算するのは

\[
 a_m=\frac{rmf}{1000}qTc^{(T-15)/10}\frac{2.2\,10000}{\mathrm{SLA}},\quad
 a_g=lf\frac{2.2\,10000}{\mathrm{SLA}}(1+rgf),\quad a=a_m+a_g,
\]
\[
 c=P\left(\frac{Ph}{Ph-24a}-1\right),\qquad
 L^*=\frac1k\log\max\left(1,\frac{kqI}{c}\right)\quad(P>0).
\]

P≤0ではL*=0。非特異で採算が正の枝（a>0、Ph>24a）では

\[
 L^*=\frac1k\left[\log\frac{kqI(Ph-24a)}{24aP}\right]_+.
\]

この整理により、L*の正負の境界を明示的に求めやすい。
**これは固定環境での目標値の一意な代数計算であり、それ自体が複数の植生平衡を意味しない。**
また、前回の`3(C_S+C_R)/(30+C_S+C_R)`という支持組織依存の目標ではない。

注意すべき原典の細部：

- 葉のコストを計算する箇所だが、温度係数はコード上`qTc`であって`qTf`ではない。
- `qTc`は`f_q10_ar`で温度依存に更新される。定数Q10への置換と混同しない。
- Ph=24a、a=0、k=0、SLA=0などには分母の問題がある。
  ソース忠実な関数では未定義として検出し、黙ってepsilonを足さない。
- Pはµmol CO₂ m⁻² s⁻¹、qはmol CO₂ mol photon⁻¹、Iはµmol photon m⁻² s⁻¹、hはhour。
  aはソース内のコスト中間量であり、**上記のP・時間と同じ基準への単位換算が
  式内で明示されていない**。数値式の再現と次元整合性の確認を分ける。
  根拠なく換算係数を補って「VISITの式」とは呼ばない。
- Ph≤24aをL*=0とする物理的な延長は、特異点を含む元の浮動小数計算と区別し、
  必要なら別バリアントとして保存する。単位監査が完了しなければ定量的な解釈は保留する。

### 3.3 温度依存の入力を閉じる

最初は光、日長、SLA、消散係数、CO₂を固定し、P(T)、q(T)、qTc(T)を同じソース系列から与える。
Pは`photosynthesis.c::f_pc_sat` 54–113、qは`ecophysiology.c::f_photo_qy` 179–192、
Q10は同`f_q10_ar` 303–321を参照する。
ciを固定する第一近似と、元の気孔–ci反復（`ecophysiology.c` 25–51）を使う監査を区別する。
ciの固定値は参照データから取得し、未確認値を推測しない。
根・土壌温度はTへ一致させる第一近似を明示し、独立の可変気象入力を増やさない。
SLA季節変化とフェノロジーはこの段階では固定する。

## 5. allocation.cの配分を8状態へ適応する方針

非作物、活動期（season=1）で、a_f=alloc_ass、a_s=alloc_abg、E=EPP>0とする。
Δ=(L*−L)/γ、a_f>0の範囲では、葉配分率は次の**ソースどおりの区分式**になる。

\[
 c_f=\begin{cases}
 0&L>L^*,\\
 a_f&L\le L^*,\ \Delta\le a_f E,\\
 \min(\Delta/E,0.05)&L\le L^*,\ \Delta>a_f E.
 \end{cases}
\]

幹・根配分は(1−c_f)a_s、(1−c_f)(1−a_s)。休眠時の0.7係数は今回固定した活動期には適用しない。
出典：`allocation.c` 25–63、75–77。Eはネイティブの1日分の量として比較する。
**L=L*でも葉配分がa_fのまま残り、L>L*でゼロになる。**
さらにa_f>0.05の場合には別の切替不連続もあり得る。コメントの「最大5%」を
全分岐共通の上限として実装し直さない。a_f=0の元コードの0除算も別途検査する。

8状態のODEへ取り込む際、GPPをN_Lへ入れた後、さらにEを外部入力として加えてはならない。
第一候補は各NSCからの動員 m_j=κ_j N_j と総動員V=Σm_jを定義し、
**上式のEをV Δt_ref（Δt_ref=1 day）で置き換える適応版**である。
Δも炭素量なので比較の単位が揃う。Δt_refはモデルの定義であって数値積分刻みではない。
器官iへの総投資はU_i=c_i V、供給器官jからiへはc_i m_jとし、供給NSCから必ず引く。
構造増加y_i U_i、成長呼吸(1−y_i)U_iを記録する。V=0なら全投資ゼロ。
この版では従来の展葉・幹根成長投資を置換し、二重に残さない。

これはGPP−呼吸を即時配分する原コードそのものではなく、**配分率を借用するNSC動員モデル**。
E≤0時の`alloc_f*GPP−rfm`等（`allocation.c` 82–92）を構造炭素から直接引く規則は採用しない。
負の貯留量や、除外したNSC不足由来の構造損失を再導入するためである。
原式との対応はE>0の純関数試験と、別の1日写像監査で確認する。

不連続な配分は、滑らかなODEとして通常のヤコビアンだけで扱わない。
まず各分岐内の平衡を求め、分岐条件を満たすか検査する。境界では片側ベクトル場・
滑りの可能性を調べる。平滑化幅→0、日次写像との比較により、平滑化や刻みだけが作る
多安定性を除外する。境界に到達した場合の規則を決めるまでは速度実験に進まない。

### 6.1 最優先：生きた組織の割合と維持呼吸

原コードの幹量cに対する指数と辺材量は

\[
 p(c)=1-0.33334\frac{c}{f_{sz}+c},\quad s(c)=\min(c,c^{p(c)}).
\]

根にも同形を使う。辺材・細根は独立状態とせず、C_S,C_Rからの代数量として8状態を保つ。
幹の呼吸需要は元コードの数値単位で

\[
 R_S^{dem}=\frac{qTc^{(T-15)/10}}{1000}
 \frac{C_S}{C_S+10^{-5}}\{rmc_s s(C_S)+rmc_h[C_S-s(C_S)]\}.
\]

元の冪は有次元の数値量に作用するため、転記時は基準量C_ref=1 Mg C ha⁻¹を明示し、
`C_ref*(c/C_ref)^p`として同じ単位系で再現する。
`10^-5`もソース由来のMg C ha⁻¹の数値正則化として記録する。
これを除いた極限との比較を必須とし、原点近傍の呼吸抑制による人工的な枝を判別する。
係数rmc_s>rmc_h等が実際のTKY設定で成り立つかを確認してから、維持費低下を主張する。

呼吸需要からの実支払いは現行NSCモデルの基質制限を別途掛ける。
絶対貯留量型N/(K+N)と、比較用の濃度型N/(κC+N)を区別する。
後者はVISITからの転記ではない。C=N=0の呼吸はゼロと定義し、epsilonを足さない。
呼吸則と支払い制限を同時に変えず、同じ需要に対する対照で数値的な発生要因を切り分ける。

### 6.2 貯蔵優先

樹木の容量は `N_cap=0.1*stm_sp+0.3*rot_fn`（`ecophysiology.c` 80）。
原コードは単一のnsch_storageが容量未満なら幹向け、次いで根向けの正の配分を貯蔵へ回す。
容量まで正確に充填するmin規則ではなく、1ステップで容量を超え得る。
8状態版ではN_S+N_Rを容量と比較する第一候補を置き、N_Lを含む定義は感度比較に分ける。
原典の単一貯蔵との対応は近似である。容量は新しい炭素入力ではない。
成長抑制でNSCに留める流量と、構造へ出す流量を保存則で結び、ハード切替と連続近似を別扱いにする。

### 6.3 群落GPPと温度係数

L=γC_L、b=kqI/Pとして、原コードのGPPは

\[
 G=\frac{2Ph\,lTs}{k}\log\frac{1+\sqrt{1+b}}{1+\sqrt{1+b e^{-kL}}},
 \quad lTs=3600\times12/10^8.
\]

出典：`photosynthesis.c` 33–37、`definition.h` 33。単位はMg C ha⁻¹ day⁻¹。
P≤0はG=0。固定された正のP,q,I,kではG(0)=0、葉量に対して単調増加・飽和する。
そのため、これを導入しただけで多安定になるとは予想しない。
Q10(T)=Q10_0 exp[−0.009(T−15)]も温度を固定すれば定数で、遅い順化状態ではない。
光合成の凍土閾値（`photosynthesis.c` 84–88）を横切る実験は、滑らかな昇温実験から分離する。

### 6.4 救済再配分は「生存側」の対照

樹木の臨界LAIは0.1、臨界葉炭素はc_crit=0.1/γ。
C_L<c_critなら、元コードの幹から葉への1日移行量は

\[
 H_S=c_{crit}\,alloc_{abg}\frac{0.05C_S}{0.5c_{crit}+0.05C_S},
\]

根は0.05C_Sを0.1C_R、alloc_abgを1−alloc_abgに置き換える。
**供給元は構造炭素であってNSCではない。** NSCから支払う版を作るなら別仮定である。
連続化する場合はH/Δt_refを内部移行として幹根から引き、葉へ同量を足す。
供給量と1日移行量の大小・非負性をまず監査し、追加制限が必要なら修正と明示する。
低葉量の回復を助けるので、これを「多安定性を作りそう」と一方向に評価しない。
`allocation.c` 156–168の目標LAIまで増やす別案はコメントアウトされており、採用済み処理に数えない。

## 7. 解析を容易にする手順

1. 土壌は植物へ逆流しないため、まず植物6状態の平衡を求める。
   入力I_N,I_Cが決まればN_O*=I_N/(k_N f_O)、C_O*=(I_C+αI_N)/(k_C f_O)で復元できる。
   ただし土壌も非負性・収支の検査対象とし、時系列は8状態すべてを積分する。
2. 解析補助系では器官比率と配分分岐を固定し、NSC平衡を消去してバイオマスbの
   残差F(b,T)=0へ縮約できるか調べる。消去解の非負性と分岐条件を必ず代入検査する。
3. サイズ依存維持費の効果は、補助的な正味増加率h(b,T)を使うと見通しがよい。
   `dot b=b h(b,T)`で、h(0+,T)<0、中間でh>0、大きなbでh<0なら、
   連続性の下で少なくとも二つの正の零点が期待される。単純な横断なら低い根が不安定、
   高い根が安定になる。これは1次元補助系の条件で、8状態の安定性は別に固有値で確認する。
4. G(b)/bが減少し、損失の単位炭素当たり率が非減少なら、一意性を先に検討する。
   サイズ依存呼吸は後者を崩し得る候補であって、多安定性の証明そのものではない。
5. 直接多始点根探索＋pseudo-arclengthで安定・不安定枝を追う。
   滑らかな枝のfoldはF=0と零固有値、横断性・非退化性で検証する。
   ハード切替の境界衝突を通常のfoldと同一視しない。
6. 局所安定な根が見つかってから多初期値spinup、鞍点両側、必要に応じedge trackingへ進む。
   根を求めやすいことと、その根が安定であることは別の判定である。

## 9. 実行順と合格条件

### WP-A：転記監査

目標LAI、LAI換算、配分、サイズ依存呼吸の純関数を作る。
小さなCハーネスで元関数と比較し、分岐境界、ゼロ、単位変換、更新順序を確認する。
過去のPython式よりCを優先する。次元の未解決点があれば定量実験へのgateとして報告する。

### WP-B：死亡なし基準と目標置換

V0→V1f→V1tを実行。NSC死亡が全条件でゼロであることをテストする。
同時に変えるのは目標値のみ。全炭素収支は
`sum(dot x)=G−R_maintenance_paid−R_growth−R_soil−E_external`。
未払い需要や内部再配分を外部損失に数えない。

### WP-C：凍結温度の枝と過程比較

ソース式の有効範囲内で、まず前回の10,15,20,25,30,35,40℃を候補にし、
目標ゼロ境界・特異点の周辺は別に細分化する。無効な温度点を無理に計算しない。
各温度で微小植生、低/高構造炭素×低/高NSC、平衡近傍からspinupする。
V2–V7は上記の分離比較に従い、根数、固有値、収支、無植生侵入、吸引域を記録する。
解析的に一意性が示せたケースも結果として残す。

### WP-D：速度実験

正の安定枝が全経路で存在する温度区間のみを採用する。
同じ端点で30日、1年、10年、100年の滑らかなランプ、step、線形、熱パルス、遅い復帰を比較。
全実験は一定温度spinupから開始し、終点を500年保持する。
緩和固有値と残差に応じて2000年以上へ延長し、上限で未収束なら未判定とする。
低速で追跡・高速で別吸引域・長期収束・枝存続・数値精度・境界横断を確認できた場合のみ
R-tippingと呼び、速度二分探索へ進む。

### 数値基準と停止条件

- 非負性をクリッピングで保証しない。積分中の内部点も検査する。
- 初期基準はmax|F|<10⁻⁹ Mg C ha⁻¹ day⁻¹、年変化<10⁻⁷（max(1,x)尺度）。
- 最大刻み半減で尺度化状態差<10⁻⁵、代数収支残差<10⁻¹¹ Mg C ha⁻¹ day⁻¹。
- 外部収支の累積も独立積分し、状態総量との差を保存する。
- 特異点・ハード切替・ゼロ濃度・ソースの正則化に依存した見かけの安定点は別分類。
- 多安定性やR-tippingがなければ、その理由と調べた範囲を報告し、係数を後付けで調整しない。
