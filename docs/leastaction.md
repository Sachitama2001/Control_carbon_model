# 研究計画書
## 最小作用・随伴感度・ISSを用いた陸域炭素貯留非平衡の上下界評価
### ― E4炭素・水理結合モデルによる概念実証 ―

**研究段階：理論構築・数値検証計画**

### 1. 研究背景と目的

Luoら（2017）の炭素貯留理論では、炭素入力速度と滞留時間によって決まるcarbon storage capacityが、時間変化する参照量として定義される。実際の炭素ストックはこのcapacityに遅れて応答し、その差がcarbon storage potentialとなる。

本研究の最終目標は、VISIT等の高次元陸域生態モデルにおいて、全状態変数の長期シミュレーションを反復実行することなく、限られた気象情報、炭素移送構造および初期状態から、次の量を保証付きで評価することである。

1. Carbon storage capacityの変化方向と変動範囲。
2. Carbon storage potentialの上下界。
3. 指定期間内に不可避的に発生する非平衡の最小規模。
4. 総炭素量および特定炭素プールの増減方向。
5. Capacityへの追従を妨げる力学的要因とその寄与。

特に本研究では、従来のISSによる誤差上界に加え、**「気象変動が生じた以上、少なくともこれだけの非平衡が発生する」という下界**の導出を主要課題とする。

そのため、最小作用の原理を最適制御の意味で導入する。ただし、最小作用の値をそのまま自然系の非平衡度と同一視せず、両者の関係を厳密に検討する。

### 2. 基本モデル

#### 2.1 E4の状態変数

既存の有理関数型E4を使用する。

\[
y=(\psi_x,\psi_l,C_L,C_W,C_R,C_S)^\top
\]

ここで、\(\psi_x,\psi_l\) は木部・葉水ポテンシャル、\(C_L,C_W,C_R,C_S\) は葉・木部・根・土壌炭素量である。

全系は

\[
\dot y=F(y,v(t))
\]

と表され、**外部時変入力はVPD \(v(t)\) のみ**とする。

第一段階では根水ポテンシャルを従来どおり固定し、既存の解析結果との比較可能性を維持する。

土壌–根抵抗モデルは独立した後続実験とし、初期段階で複数の変更を同時に導入しない。

#### 2.2 炭素部分系

\[
\dot C=MC+bA(C_L,\psi_l)
\]

とする。既存E4では、\(M\) は安定な定数Metzler行列である。

\[
K=-M^{-1}bA(C_L,\psi_l)
\]

をLuo型の瞬間carbon storage capacityと定義する。

Carbon storage potentialを

\[
P=K-C
\]

と定義する。

したがって、

\[
\boxed{\dot P=MP+\dot K}
\]

が厳密に成立する。

また、

\[
K=v_KA,\qquad v_K=-M^{-1}b
\]

であるから、

\[
\boxed{
\dot K=v_K\left(
A_{C_L}\dot C_L+
A_{\psi_l}\dot\psi_l
\right)
}
\]

となる。

本研究ではこの恒等式を、VPDからcapacityの変動を評価する出発点とする。

なお、\(K\) は瞬間的な炭素貯留参照量であり、一般には全6変数系の平衡点ではない。

### 3. 中心仮説

**仮説H1：** E4の炭素移送行列の正値性を利用すれば、全6状態の共通Lyapunov評価よりも鋭いcarbon storage potentialの成分別上界・下界を構成できる。

**仮説H2：** VPDの変化方向、振幅、継続時間と初期状態に一定の条件を置けば、capacityの変動方向と、不可避的な非平衡の正の下界を保証できる。

**仮説H3：** 最小補償作用は、炭素移送系の時間尺度とcapacity追従困難度を特徴づける補助指標となる。ただし、自然なpotentialの大きさとの対応は、対象出力や補償制約に依存する。

**仮説H4：** 全状態の誤差ノルムではなく、総炭素や土壌炭素などの観測量を指定して随伴・双対評価を構成することで、より少ない内部状態情報から実用的な保証が得られる。

これらは検証すべき仮説であり、現時点でE4について証明された結論ではない。

### 4. 理論課題A：非平衡の下界

#### A1. Capacity変化の端点差による下界

期間 \([0,T]\) において、

\[
\|M(t)\|\le L
\]

が成立するとする。

\[
P_{\max}=\sup_{0\le t\le T}\|P(t)\|
\]

と定義する。

炭素方程式を積分すると、

\[
K(T)-K(0)
=
P(T)-P(0)-\int_0^T M(t)P(t)\,dt
\]

である。

したがって、

\[
\boxed{
P_{\max}\ge
\frac{\|K(T)-K(0)\|}{2+LT}
}
\]

を得る。

さらに \(P(0)=0\) なら、

\[
\boxed{
P_{\max}\ge
\frac{\|K(T)-K(0)\|}{1+LT}
}
\]

となる。

この下界は全系平衡を求めずに導出できる。

ただし、E4では \(K(T)\) が内部状態に依存するため、次の課題は、フル軌道積分を行わずにcapacity端点差の保証下限を求めることである。

#### A2. 一方向のcapacity変化による下界

固定行列 \(M\) に対して、

\[
P(t)=e^{Mt}P(0)+
\int_0^t e^{M(t-s)}\dot K(s)\,ds
\]

が成立する。

E4では \(e^{Mt}\) が成分ごとに非負である。

したがって、例えば

\[
P(0)\ge0,\qquad
\dot K(t)\ge m(t)\ge0
\]

が成分ごとに成立するなら、

\[
\boxed{
P(t)\ge\int_0^t e^{M(t-s)}m(s)\,ds
}
\]

が成分別に成立する。

負方向への単調変化についても、符号を反転して同様の評価を構成する。

**検証課題：** E4のVPDランプ中に、\(\dot K\) の成分別符号を保証できる状態領域が存在するか。

#### A3. 下界の対象量を区別する

次の三種類を別々に扱う。

\[
L_{\rm peak}\le
\sup_{0\le t\le T}\|P(t)\|
\]

\[
L_{\rm final}\le\|P(T)\|
\]

\[
L_{\rm cumulative}\le
\int_0^T\|P(t)\|\,dt
\]

初期状態で \(P(0)=0\) なら、全期間の点ごとの最小非平衡は必ずゼロとなる。このため、最初の主対象は**期間最大非平衡の下界**とする。

### 5. 理論課題B：最小作用の導入

#### B1. 作用の意味を固定する

Hamiltonの保存系に対する作用ではなく、最適制御における最小補償エネルギーを採用する。

仮想的な補償フラックス \(a(t)\) を導入し、

\[
\dot P=MP+\dot K+Ba
\]

とする。

ここで \(B\) は補償が作用する炭素プールを指定する行列である。

作用汎関数を

\[
\boxed{
\mathcal A[a]
=
\frac12\int_0^T a(t)^\top R a(t)\,dt
}
\]

と定義する。\(R\) は正定値の重み行列であり、単位と物理的意味を明示する。

最初の実験では \(B=I\) とし、全炭素プールへの仮想補償を許す。

次に、葉への炭素入力だけを操作する \(B=b\) など、より制限された補償構造を試す。

これらは追従困難度を測るための**仮想操作**であり、E4の実際の外部入力を増やすものではない。

#### B2. 最小補償作用の計算

終端条件を

\[
P(T)=0
\]

とし、

\[
\boxed{
\mathcal A_{\min}
=
\inf_{a:P(T)=0}\mathcal A[a]
}
\]

を計算する。

まず \(K(t)\) を外生的な既知関数として固定した線形ベンチマークを解く。

可制御性Gramianを

\[
W_T=
\int_0^T
e^{M(T-s)}BR^{-1}B^\top e^{M^\top(T-s)}\,ds
\]

と定義する。

無補償の終端誤差を \(P_{\rm nat}(T)\) とすると、\(W_T\) が正則な場合、

\[
\boxed{
\mathcal A_{\min}
=
\frac12P_{\rm nat}(T)^\top
W_T^{-1}P_{\rm nat}(T)
}
\]

となる。

Gramianが特異な場合は到達可能性を判定し、到達可能な場合に限り擬似逆行列を用いる。

#### B3. 最小作用と非平衡下界の接続

補償作用に上限

\[
\mathcal A[a]\le E
\]

があるとき、出力 \(w^\top P(T)\) に対して、Gramianを用いた補償可能量の上界を導出する。

この上界と無補償出力との差から、補償後にも残る不可避な非平衡を評価する。

ただし、**補償作用の最小値が大きいことだけから、自然なE4のpotentialの正の下界が従うわけではない**。

この接続条件を明示的に証明する。

#### B4. 内生capacityへの拡張

実際のE4では、

\[
K=K(C_L,\psi_l)
\]

であり、補償入力を炭素方程式へ加えると \(K\) 自身も変化する。

したがって、外生capacityのGramian公式をそのまま全結合E4へ適用しない。

拡張は次の順序で進める。

- 固定capacity経路に対する厳密な線形問題。
- 基準軌道周りの線形化された全結合E4。
- 非線形最適制御問題と線形近似の誤差評価。

### 6. 理論課題C：随伴方程式と出力別の上下界

総炭素potentialまたは土壌炭素potentialを

\[
J(T)=w^\top P(T)
\]

と定義する。

固定 \(M\) に対して、

\[
\dot\lambda=-M^\top\lambda,
\qquad
\lambda(T)=w
\]

という随伴方程式を導入する。

このとき、

\[
\boxed{
J(T)=
\lambda(0)^\top P(0)+
\int_0^T\lambda(t)^\top\dot K(t)\,dt
}
\]

が成立する。

したがって、全状態の誤差上界ではなく、

\[
\lambda(t)^\top\dot K(t)
\]

という**指定した炭素出力に実際に寄与する量**の上下界を構成する。

優先する出力は、

1. 総炭素potential。
2. 葉炭素potential。
3. 土壌炭素potential。
4. 総炭素変化率。

特に、\(\dot K=v_K\dot A\) というE4の低ランク構造を利用し、随伴評価をスカラーの光合成変化率の評価へ還元できるか検討する。

### 7. 理論課題D：VPDからcapacity変化を保証する

ここが本研究の最も重要な未解決課題である。

E4では、

\[
A=A(C_L,\psi_l)
\]

であるため、VPD変化率の下限だけから \(\dot A\) の符号や大きさは一般には決まらない。

そこで、次の情報レベルを設定する。

**情報レベルI：** VPDの完全な時系列と初期状態が既知。

**情報レベルII：** VPDの上下限、最大・最小変化率、継続時間が既知。

**情報レベルIII：** VPDの端点差、総変動量、継続時間のみ既知。

各情報レベルについて、状態領域の比較原理、区間解析、感度解析を用いて、

\[
\underline{\dot A}(t)
\le\dot A(t)\le
\overline{\dot A}(t)
\]

または

\[
\underline{\Delta A}
\le A(T)-A(0)\le
\overline{\Delta A}
\]

を保証できるか調べる。

これを

\[
K=v_KA
\]

へ代入し、capacity変化の上下界を得る。

なお、VPDの変化率に下限があるだけでは、初期水理状態による相殺や応答遅れが起こり得る。正の下界が存在しない入力クラスについては、反例を構成して適用限界を明確にする。

### 8. 数値実験計画

#### Experiment 0：既存結果の再現

既存E4のパラメータ・単位・初期条件を固定する。

VPD 2.44 kPaの正平衡を基準に、過去のISS・移動平衡追従実験を再現する。

基準出力として \(C(t)\)、\(K(t)\)、\(P(t)\)、\(\psi_l(t)\)、光合成速度を保存する。

この段階ではモデル方程式を変更しない。

#### Experiment 1：線形炭素系での最小作用の検証

既知の外生capacity経路を与え、四プール炭素系について最小作用を計算する。

Gramian公式、数値最適制御、直接積分による結果が一致することを確認する。

作用の重み行列 \(R\)、時間幅 \(T\)、補償入力行列 \(B\) を変え、作用の意味と到達可能性を調べる。

#### Experiment 2：E4のcapacity変化方向の解析

VPDを次のように変化させる。

- 2.44 → 2.54 kPaのランプ。
- ランプ時間10日、1年、10年、100年。
- 一定VPDでの保持。
- 元のVPDへの回復ランプ。
- 既存の木部閉鎖に近づく強乾燥条件。

各条件で \(\dot A\)、\(\dot K\)、\(P\) の符号変化と極値を調べる。

フルODE解は、この段階では**理論の検証用の正解軌道**として使用する。

#### Experiment 3：保証付き下界の構築

Experiment 2の各条件に対して、以下を求める。

- Capacity端点差による最大非平衡下界。
- 成分別比較原理による下界。
- 随伴出力による下界。
- 従来のISS上界。

初期potentialがゼロの場合と、非ゼロの場合を分けて評価する。

#### Experiment 4：最小作用と実際の非平衡の比較

同じVPD条件で、

\[
\mathcal A_{\min},\quad
\sup_t\|P(t)\|,\quad
\|P(T)\|
\]

を比較する。

最小作用と非平衡の関係が、単調なのか、初期状態や補償方向に依存するのかを検証する。

相関が見られても、それだけで普遍的な不等式が成立すると結論しない。

#### Experiment 5：フルシミュレーション不要性の評価

各保証方法について、以下の計算コストを記録する。

- 必要なモデル内部情報。
- 必要なJacobian・感度情報。
- 区間評価または最適化の計算時間。
- 前処理の計算時間。
- 新しいVPDシナリオ一件あたりの計算時間。

**多数のVPDシナリオを評価する場合に、フルモデルの反復積分より安価か**を主要な性能指標とする。

### 9. 成功基準

本研究の成功は、単に理論上界・下界が正しいことだけでは判断しない。

**数学的妥当性：** 仮定、保証領域、計算誤差が明示され、成立範囲内で上下界が破れない。

**下界の非自明性：** 少なくとも一つの実用的なVPD条件で、最大非平衡の下界が厳密に正となる。

**鋭さ：** 保証下界が実際の最大非平衡に対してどの程度の割合を捉えるかを定量化する。最初の段階では、下界がゼロに潰れる条件の特定も成果とする。

**情報効率：** 必要な気象情報を減らしたとき、保証の鋭さがどのように低下するかを測定する。

**計算効率：** 初期の構造抽出費用と、シナリオごとの追加費用を区別し、フルODE反復積分と比較する。

**生理学的整合性：** 木部通水停止、葉炭素ゼロ、正平衡の不安定化に近づく領域では、保証の成立条件を個別に検証する。

### 10. 高次元モデルへの拡張条件

E4で有効性が確認された後、次の順序で複雑化する。

1. 土壌–根抵抗を含むE4。
2. 動的土壌水分を含むE4。
3. 状態依存炭素移送行列を持つE4。
4. 多プール炭素モデル。
5. VISIT型モデル。

高次元モデルでは、\(M\) の明示的な逆行列計算に依存せず、疎行列線形方程式や随伴解法を利用する。

また、非線形炭素フラックスを \(M(y)C+u(y)\) と表現する際には、分解の一意性が一般には保証されない。Luo型capacityの解釈を維持するため、炭素フラックスの配分・移送・損失の定義を固定する。

### 11. 期待される研究成果

**成果1：** E4におけるLuo型carbon storage potentialの成分別上下界。

**成果2：** VPD変動によって不可避的に発生する非平衡の正の下界と、その成立条件。

**成果3：** 最小補償作用によるcapacity追従困難度の定量化。

**成果4：** 随伴・双対法を利用した、総炭素や土壌炭素などの出力別保証。

**成果5：** どの程度の気象・内部状態情報があれば、フルシミュレーションなしで意味のある保証を構成できるかについての方法論。

### 12. 最初に実装すべき最小実験

初期段階では、次の四項目に限定する。

1. **既存E4から \(M\)、\(b\)、\(A\)、\(K\)、\(P\) を取り出す共通解析インターフェースを作る。**
2. **外生capacityを与えた四プール炭素系で、Gramianに基づく最小作用の公式を検証する。**
3. **既存のVPDランプ実験で、capacity端点差による非平衡下界と実際の最大非平衡を比較する。**
4. **\(\dot K\) の符号を保証できる領域を探索し、最初の非自明な成分別下界を導出する。**

この四項目が完了するまでは、E4の水理構造や炭素プール数を変更しない。

### 研究の中心命題

**「陸域生態モデルの限られた構造情報と気象強制の特徴量だけから、Luo型carbon storage capacityの変化と、それに対する炭素ストックの不可避的な追従誤差を、上下両側からどこまで保証できるか。」**

最小作用は、その追従困難度を測る補助的な幾何学的・制御理論的指標として導入する。最終的な評価対象は、実際の炭素貯留量とcapacityの差、およびその変化方向とする。
