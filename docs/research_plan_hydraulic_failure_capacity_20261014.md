# 次段階の実装指示：炭素–水理結合系の平衡条件を一変数に帰着する

## 目的

現行のManzoni–炭素結合モデルについて、平衡点の存在・個数・安定性と、Luo型carbon storage capacityとの対応を解析する。

今回の作業では、新しい生理モデルや大規模なbasin探索を追加しない。まず既存の方程式を代数的に整理し、証明可能な命題を抽出する。

## 対象

基準コミット：`629314706aaac5f2f78ff37f6e19f01a01d58b42`

優先モデルはE0、E1、E4とする。元の水理モデルとの対応を維持し、既存のStage A〜Cの実装は変更しない。

## 作業1：平衡条件の導出

1. 炭素4プールの平衡条件から、W、R、Sを葉炭素Lで表す。
2. 葉炭素平衡から気孔開度hをLの関数として求める。
3. Manzoniの気孔conductance関数を反転し、葉水ポテンシャルをLで表す。
4. 木部の水収支から木部水ポテンシャルを消去する。
5. 最終的に、正の通水・正の葉炭素の平衡条件を `D = D_curve(L)` に帰着する。
6. 変数消去で除外されたゼロ炭素根、非通水平衡、区分関数の折れ点を別途列挙する。

## 作業2：根の個数と安定性

1. 関数の定義域を解析的に特定する。
2. `D_curve'(L)=0` を求め、fold候補と根の個数を分類する。
3. 可能なら単調区間の個数を証明する。証明できない場合は探索範囲を限定し、区間保証と単なる数値走査を区別する。
4. 各平衡から全6状態を復元し、元のODE残差と全Jacobian固有値を検証する。
5. 平衡点の個数、安定な平衡点の個数、各平衡でのcapacityベクトルをVPDの関数として表示する。

## 作業3：非通水状態とcapacity消失の命題

1. 木部・気孔conductanceのゼロ条件を原式から特定する。
2. `g_s=0 ⇒ GPP=0 ⇒ K=0` を証明する。
3. 非通水状態が不変となる条件を水理ODEから示す。
4. その条件下で炭素ストックがゼロへ減衰することを、炭素行列の安定性から証明する。
5. 現在の正葉量モデルの定義域と、形式的なゼロ炭素極限を明確に区別する。
6. 非通水平衡集合を孤立した双曲的な安定平衡と誤記しない。

## 作業4：最小限の数値実験

1. 既存のManzoni unsafe設定を最初の基準例とする。
2. 正の通水平衡が複数存在するVPDを選ぶ。
3. 異なる初期水ポテンシャルから積分し、通水側と非通水側への帰結を調べる。
4. 炭素を結合した場合は、各軌道について `g_x、g_s、GPP、K、C` を同時に表示する。
5. E0とE4を比較し、炭素から水理へのfeedbackにより平衡構造がどう変化するか確認する。

## 成果物

- 一変数への変数消去を省略せずに記した数式ノート
- 平衡個数と安定性の分類表
- VPD–葉炭素平衡曲線
- 各平衡に対応するcarbon storage capacity
- 非通水状態でのcapacity消失の命題・証明
- 再現可能な代表初期値と時系列図

解析的に証明したこと、限定範囲で数値確認したこと、まだ未解決なことを明確に分離すること。

**停止条件：** まず平衡条件の一変数帰着、正根の分類、非通水状態でのcapacity消失命題まで完了する。それ以降の非自律ramp・大域basin・新しい死亡機構は実装しない。
