# VISIT準拠葉量配分実験：第1段階（V0–V3）

## 1. この段階で行ったこと

`temperature_nsc_visit_allocation_research_plan.md` のうち、WP-BとWP-C前半を実装した。8状態
$X=(C_L,C_S,C_R,C_O,N_L,N_S,N_R,N_O)^\top$ は維持し、NSC不足による枯死を全変種で無効化した。比較した閉包は次のとおりである。

- V0：従来の一定目標葉量、従来の光合成・維持呼吸
- V1f：20 ℃で計算したVISIT最適葉量を全温度で固定
- V1t：各温度でVISIT最適葉量を再計算
- V2：V1tにVISITの群落光合成式を追加
- V3：V2にVISITの個体サイズ依存維持呼吸を追加

ここで「VISIT準拠」は、元コードの式を縮約モデルの閉包として使ったという意味であり、VISITの日次逐次計算全体を再現したという意味ではない。

## 2. 出典と設定

式の出典は固定したVISITソース（commit `3285bd8e131a932e338b59892751648fd9edcc7b`）の `ecophysiology.c` にある `lai_mass`, `f_photo_qy`, `f_opt_lai`, `f_q10_ar`, `f_spcfc_resp` と、`photosynthesis.c` の `f_gpp`, `f_pc_sat` である。落葉広葉樹のパラメータは `Config_TKY.xlsx` の tree 列（E列）からラベルで読み込む。特に、表記が数字のゼロではなく英字Oである `lueO=0.052` を用い、`kmci=40`, `cmpcd0=50` とした。

日長12 h、林冠上端PPFD 1000 µmol photon m−2 s−1、CO2 370 ppm、$c_i=0.7c_a$、水制限係数1は、TKYファイルから得た値ではなく、この探索の固定環境仮定である。manifestでも由来を分離した。水過程を一旦置くという実験目的に従い、VISIT本来の気孔・水分反復は固定$ c_i $と固定水制限に縮約した。

## 3. 数値実験

温度10、20、30 ℃の各条件で、植物量とNSC比の異なる4初期値から、正値を保存する対数座標積分を最大500年間行った。その終点から正の定常根を求め、数値Jacobianの固有値で局所安定性を判定した。

VISIT最適LAIは10、20、30 ℃でそれぞれ9.631、8.218、6.844であり、対応する葉炭素量は5.837、4.981、4.148 Mg C ha−1だった。この設定では高温ほど目標葉量が小さくなる。

全60積分で状態量は正に保たれ、裸地近傍または数値領域境界への到達は0件だった。最小在庫量は約 $3.77\times10^{-10}$ Mg C ha−1である。15条件すべてで、4初期値から得た定常根は条件内で同一となり、各根の最大固有値実部は負だった。したがって、この有限な初期値集合と温度集合では、V0–V3のいずれにも多安定性は検出されなかった。ただし、これは大域的な一意性の証明ではない。

500年以内に時間積分の厳しい収束基準を満たしたのは60件中10件だった。未収束例でも根探索の残差は概ね $10^{-17}$ 程度で安定根が得られたが、積分軌道がその近傍まで十分に緩和していない。この違いは、遅い土壌・木部時定数による可能性が高い。以後は、(i) スピンアップ時間延長、(ii) 解析対象を植物サブシステムと遅い土壌プールに分ける、(iii) 許容値を緩めず漸近速度から必要期間を決める、の順で確認する。

## 4. 現時点の解釈

目標葉量をVISIT式に変えただけのV1f/V1t、さらに飽和型GPPとサイズ依存呼吸を加えたV2/V3は、今回の範囲では新しい吸引状態を生まなかった。これは否定的結果というより、単調な飽和と単一の目標値だけでは多安定性が生じにくい、という次の設計判断を支持する。

次に優先すべきなのは計画書のV4（VISIT `allocation.c` の区分的配分）である。状態に応じて配分則が切り替わるため、ベクトル場の区分境界が生じ、複数の自己整合的な定常状態を作る候補になる。続いてV6の貯蔵優先順位、V7の再配分救済を個別に追加し、各追加ごとに多安定性と安定性を再評価する。R-tippingの速度実験は、同一パラメータ経路上に複数吸引集合または盆境界が確認されるまで実施しない。
