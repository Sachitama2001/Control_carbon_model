# 配分・貯蔵・維持呼吸：最初の検証結果

2026-09-29。[文献・数式・証明メモ](allocation_storage_respiration_evidence.md)に対応する。
原典や既存8状態モデルの設定は変更していない。

## 1. 要約

1. 新しい理論対照の12テストを含め、関連する41テストが成功した。
2. TKY表から実際に読み込んだ呼吸係数を用いて、40条件で原C関数とPythonを比較した。
   維持呼吸の最大絶対差は 4.44×10⁻¹⁶ Mg C ha⁻¹ day⁻¹。
3. 幹・根の単位炭素当たり呼吸が、調べた2–300 Mg C ha⁻¹の5標本で
   炭素増加に対して低下した。これは必要な正のフィードバックの一要素である。
4. しかし、比光合成の低下との大小比較、三つの正の根、温度経路での吸引域横断は
   まだ検証していない。**生物学的な多安定性・R-tippingの検出結果ではない。**

## 3. 理論対照の平衡と安定性

式(A8)の無次元検算用係数：
Pmax=3, KP=1, vmax=1, Kv=0.2, rmax=0.2, Kr=0.1,
y=0.7, d=0.1, δ=0.02。
全て計算検証用であり、森林や文献から推定した値ではない。

いずれも式(A9)による唯一の正の平衡であり、ヤコビ行列の固有値の実部は負。
平衡での方程式残差は最大5.35×10⁻¹⁶未満だった。
「根を探索して一つだけ見つかった」のではなく、一意性は命題1の証明に基づく。

h=1について初期値(C,N)=(0.1,0.001),(1,3),(30,0.1)から
無次元時間400まで固定環境で積分した。
最大刻み1と0.5、相対許容誤差10⁻⁸と10⁻¹⁰を組み合わせて比較した。

- 全計算が成功し、出力標本で負の在庫はなかった。境界非負性は式からも検証した。
- 終点は解析平衡と相対誤差10⁻⁷以内で一致した。
- 独立に積分した総収支と在庫変化は絶対誤差10⁻¹⁰以内で一致した。
- 共通時刻での粗密解は相対許容差2×10⁻⁷、絶対許容差2×10⁻⁸の比較に合格した。

これらの数値積分は平衡・非負性・収支の検算であり、温度速度実験ではない。
命題1・2の証明の代わりに、有限本数の軌跡を証拠として使ってはいない。
