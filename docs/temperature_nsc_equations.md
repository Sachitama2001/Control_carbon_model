# 温度–NSCモデル：第一実装の定義・出典・事前設定

2026-09-22。研究計画の年平均・自律系を実装する独立した理論モデル。
VISIT/SEIB-DGVMの再現、TKYの較正モデルではない。水分モデルには変更を加えない。
実装は `src/control_carbon/temperature_nsc.py`、解析は `nsc_analysis.py`。

## 2. 状態・濃度・単位

|記号|意味|単位|
|---|---|---|
|C_L,C_S,C_R|葉・幹・根の構造炭素|Mg C ha⁻¹|
|C_O|土壌の遅い有機炭素|同上|
|N_L,N_S,N_R|葉・幹・根のNSC炭素|同上|
|N_O|土壌の易分解性炭素。植物NSCではない|同上|
|T,t|有効温度、時間|℃、day|
|χ,χ_i|全植物、器官の炭素重量基準NSC割合|無次元|
|G,R,U,J,I|入力・呼吸・構築投資・転流・土壌流入|Mg C ha⁻¹ day⁻¹|
|μ,τ,k,g,u|損失・turnover・分解・転流・展葉速度定数|day⁻¹|

χ=Σ植物N/(Σ植物C+Σ植物N)、χ_i=N_i/(C_i+N_i)。土壌は除外する。
全植物が厳密にゼロならχは未定義（診断出力NaN）であり、植物流量はゼロとする。
無植生系は土壌分解のみで、土壌もゼロなら厳密な平衡。任意のepsilonを足さない。

観測値qがNSC乾燥重量/全乾燥重量なら、NSC炭素率f_N、非NSC組織炭素率f_Cを用い

    χ = f_N q / [f_C(1-q)+f_N q]

と変換する。全組織の炭素率f_totalが測定されていればχ=f_N q/f_total。
器官・組織の対応も必要で、乾燥重量の百分率をそのままχ_critに置かない。
コードは炭素率を必須引数とし、推測値をデフォルトにしない。

## 3. 閉じた8状態系

`Parameters` の既定値はすべて**未較正の構造探索値**。
G=Gmax f_G(T)(1-exp(-k_L C_L))、f_G=exp(-(T-Topt)²/(2σ_G²))。
GはN_Lのみに入る。維持呼吸はRdem_i=r_i C_i Q10^((T-Tref)/10)、
Rpay_i=Rdem_i N_i/(K_i+N_i)。差は未払い需要として記録するだけで、炭素を消さない。

第一実装の目標葉量は一定L*で、D=[L*-C_L]_+。
展葉投資を供給側ごとに書くと

    U_LS = u D N_S/(K_flush+N_S+N_R)
    U_LR = u D N_R/(K_flush+N_S+N_R)
    U_L = U_LS+U_LR
    U_S = k_gS N_S, U_R = k_gR N_R

幹・根の成長則は計画の未指定部分を閉じる最小の仮定であり、観測に由来しない。
葉NSCは成長に直接使わず、転流してから使う。転流はL→S、L→R、S→L、R→Lの
4本で、それぞれ供給側NSC×速度定数。順序付きの日次優先配分は再現しない。

μ=μ0+μmax/[1+(χ/χcrit)^n]、l_i=τ_i+μ、保持率ηを用いて

    dot C_i = y U_i - l_i C_i                        (i=L,S,R)
    dot N_L = G - Rpay_L - l_L N_L - J_LS - J_LR + J_SL + J_RL
    dot N_S = J_LS - J_SL - U_LS - U_S - Rpay_S - l_S N_S
    dot N_R = J_LR - J_RL - U_LR - U_R - Rpay_R - l_R N_R
    dot N_O = η Σ l_i N_i - k_N f_O(T) N_O
    dot C_O = η Σ l_i C_i + α k_N f_O(T) N_O - k_C f_O(T) C_O

R_g=(1-y)ΣU_i、R_h=k_C f_O C_O+(1-α)k_N f_O N_O、
E=(1-η)Σl_i(C_i+N_i)。従って厳密に

    Σ dot x = G - ΣRpay_i - R_g - R_h - E.

供給プールがゼロのとき流出はゼロ。従って非負直交領域は前方不変である。
Uは流量なのでU≤Nという異なる単位の比較はしない。任意の大きなEuler刻みでは
過大引出しが起こり得る。実装はlog(x)を積分し、クリッピングで炭素を足さない。

μmax={0.002,0.02}、n={2,4,8}、転流係数倍率={0.3,1,3}、

## 5. 数値判定と限界

正の初期値からlog座標のRadau積分、既定最大刻み30日。月次/年次は保存間隔であり、
数値積分は内部でより短い刻みを使う。50年ごとに収束を確認し、上限1000年。
max|F|<10⁻⁹ Mg C ha⁻¹ day⁻¹かつ最後の1年間の相対変化<10⁻⁷を要求する。
根探索によってspinup終端を置換しない。近傍根は別途報告する。

積分と同時に外部流量の累積を独立に積分し、総炭素変化と比較する。
受理された内部刻みと区間1/4,1/2,3/4点で有限性・正値性を確認する。
植物総量が10⁻¹²に達したらnear-boundaryとして停止し、厳密な死亡や吸引域とは認定しない。
log状態<-600も数値領域限界として停止する。この停止は非負補正ではない。

昇温経路はs(q)=6q⁵-15q⁴+10q³ (0≤q≤1)、端では0,1。
初回は20→25℃、30日・1年・10年・100年、最後に500年保持する。
最大刻み半減・許容誤差1/10の再計算で状態差<10⁻⁵、流量収支残差<10⁻¹¹を要求。
温度枝は直接根探索とlog座標pseudo-arclengthで追う。根未発見は根不存在の証明ではない。

過程除去はGPP葉量依存・高温低下・Q10・展葉経路全体・NSC枯死・転流を対象とする。
「展葉のNSC支払いだけをゼロにし葉成長を維持」すると炭素が無から生じるため実施しない。
展葉経路全体の除去は、コストだけの効果を同定する対照ではないことに注意する。
葉量依存を除く対照も無植生にGPPを与えるため、生態学的に許容されたモデルではなく機構診断。

季節展葉・Floquet解析は自律系の判定が済んだ後のgateとし、第一試験では実施しない。
