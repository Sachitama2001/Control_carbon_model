# 森林・草原炭素モデル：気温・相対湿度応答台帳

2026-10-02。対象は
[被覆率・炭素11状態基準モデル](cover_carbon_baseline.md)と
[森林・草原被覆率と気候の研究計画](forest_grass_cover_climate_research_plan.md)。
本書は文献に基づく**実装設計案**であり、気象応答関数、現地較正、臨界気象値、
気候駆動R-tippingの実装・結果を報告するものではない。モデル記号・状態・面積規約は
基準モデルに従う。

## 1. 結論と提案

1. 外部入力は気温 \(T_{\rm air}\) と相対湿度 \(R\in[0,1]\)。まず飽和水蒸気圧から
   大気VPDを計算する。気温上昇は、相対湿度一定でも飽和水蒸気圧を上げてVPDを
   増加させる。
2. 温度・VPDから炭素生産へ至る経路は、葉の生化学的温度応答と気孔応答を分ける。
   ただし現行の \(P_T,P_G\) は**面積当たりNPP**なので、葉のGPPや気孔コンダクタンス
   をそのまま代入しない。自養呼吸を含むNPPデータがなければ応答係数は未同定のままとする。
3. 相対湿度が火災時の燃焼挙動を左右するというCerradoの実験的根拠はある。しかし
   現行の \(\phi(g)\) は火炎強度や発火確率ではなく、森林から草原への**実効被覆転換率**。
   湿度から \(\phi_1\) へ直接の経験式を当てず、燃料水分・地表燃料量・着火・風を介す。
4. 木本加入 \(\alpha\) は乾燥・火災から影響され得るが、文献の苗木生存率をそのまま
   被覆転換率へ置き換えられない。初回の気候応答では \(\alpha\) を固定する。
5. \(k_D,k_H\) は土壌温度・土壌水分を要する。大気相対湿度を土壌含水率として使わない。
   土壌側の状態・forcingがない現在の11状態版では、分解係数を固定する。
6. したがって最初に実装可能なものは \(T,R\mapsto e_s,e_a,\mathrm{VPD}_{air}\) の
   単位明確な変換と検査である。生産・火災・加入の係数を有効化するのは、
   対応するサイト・機能型データが揃ってからとする。R-tippingを作る目的で関数形や
   符号を選ばない。

## 2. 気象入力の定義と導出

FAO-56の気温式を候補にする（Allen et al., 1998, Ch. 3）：
\[
e_s(T)=0.6108\exp\!\left(\frac{17.27T}{T+237.3}\right)\quad[\mathrm{kPa}],
\]
ここで \(T\) は °C。FAOの標準的な適用範囲 \(0\)–\(50^\circ\mathrm C\) を外挿しない。
相対湿度が百分率なら \(R=RH_{\%}/100\)。同時刻・同じ高さの空気温度と湿度に対して
\[
e_a=R e_s(T),\qquad D_{\rm air}=e_s(T)-e_a=e_s(T)(1-R).
\]
\(e_a\) は実際の水蒸気圧、\(D_{\rm air}\) は大気VPDで、単位はいずれもkPa。
相対湿度低下または気温上昇は \(D_{\rm air}\) を大きくするが、これは土壌水分や
植物・燃料の含水率と同じ状態変数ではない。

大気VPDは葉温 \(T_{\rm leaf}\) を使う気孔モデルの葉面VPDとも厳密には異なる：
\[
D_{\rm leaf}=e_s(T_{\rm leaf})-e_a.
\]
現行計画の外力は \(T_{\rm air},R\) のみなので、\(T_{\rm leaf}=T_{\rm air}\) は
計測またはエネルギー収支で検証するまでは明示的な近似に限る。
日平均値から計算する場合、非線形性のため
\(D(\overline T,\overline R)\ne\overline{D(T,R)}\) が一般的。利用可能なら各時間刻みで
VPDを計算してから集約する。温暖化のみ・RH一定はVPDも増える試験であり、
VPD一定の温暖化試験とは別の介入である。

## 4. 現行モデルの各係数への経路と採否

| 係数・関数 | 想定される気象経路 | 実装案・現段階の扱い |
|---|---|---|
| \(P_T,P_G\)：面積当たりNPP | \(T\) は光合成生化学・呼吸へ、\(D_{\rm leaf}\) は気孔閉鎖・CO₂同化へ作用。土壌水分・林冠光・季節も効く | 最も直接の炭素応答候補。ただし機能型・サイト別の曲線なし。まず \(P_i(T,R)=P_{i,\rm ref}f_{i,\rm NPP}(T,D_{\rm leaf})\) をデータから推定する。葉モデルを使う場合はGPPと \(R_a\) を分けてNPP化し、\(R_a\) を二重控除しない。積 \(f_Tf_D\) は独立性の仮定なので、温度×VPDの相互作用を含む同時モデルと照合する |
| \(\alpha\)：草原→森林の実効被覆転換 | 苗木の発芽・定着・生存・成長、乾季水分、火災頻度、再萌芽が段階的に被覆変化へ寄与 | 苗木実験から年率 \(\alpha(T,R)\) へ直接換算しない。現段階は固定。将来は苗木コホートから面積転換までの対応と単位時間を定めた場合だけ \(f_{\rm establish}\) を作る |
| \(\phi_0,\phi_1\)：森林→草原率の低/高草本極限 | 草本量・燃料連続性が火災伝播・燃焼・木本topkillを変える。焼却時RH/Tは燃料水分・火災挙動に作用 | 気象はまず燃料水分/燃料量/火災過程へ入れる。既存ロジスティック形を保つ縮約案は \(\phi(g,z)=\phi_0+\Delta\phi_{\rm ref}q_{\rm fire}(z,F_{\rm fine},I,W)\,S(g;\theta_c,w_c)\)。\(z\) は細粒枯死燃料水分、\(F_{\rm fine}\) は地表細燃料、\(I,W\) は着火・風など固定/観測条件。\(q_{\rm fire}\) と \(\Delta\phi\) は未同定で、実装前に焼却データと被覆遷移を対応づける |
| \(\theta_c,w_c\)：被覆シグモイドの閾値・幅 | 燃料連続性、草本の空間配置、火災フィードバックの応答幅が変われば変わり得る | 気温関数として任意に動かさない。初回は固定し、独立な被覆–燃料–火災データが得られる場合のみ再推定する。土壌含水率を表す \(\theta_s\) と記号を混同しない |
| \(p_{ij}\)：NPPの部位配分 | 温度・乾燥・フェノロジーで器官別配分が変化し得る | 現行は一定配分という構造仮定。観測された葉/茎/根配分や器官別生産がなければ動かさない。行和1と全炭素予算を常に保つ |
| \(d_{ij}\)：生体プールturnover | 温度、乾季落葉、損傷、個体サイズ・機能型が影響し得る | 分解率 \(k_D\) と混同せず、器官別寿命・落葉・枯死データが得られるまで固定。生存/死亡を炭素移転と別に二重計上しない |
| \(b_{ij}\)：被覆転換時の即時放出割合 | 火災強度は燃焼/残渣比に作用し得るが、基準式の \(r_i\) は全ての被覆転換を表す | 火災の燃焼完全度として流用しない。火災専用過程を導入するなら火災発生・燃焼・非燃焼topkillを区分し、そのデータから別に定義する。基準版は固定、草原→森林転換では0 |
| \(k_D,k_H,\rho_i\)：枯死物/腐植分解と配分 | 微生物分解は土壌温度・水分、基質・土壌性質に作用される。乾燥後再湿潤に過渡応答もあり得る | \(T_{\rm air},R\) だけで更新しない。将来は \(T_s,\theta_s\) を入力/状態として、例えば \(k_D=k_{D,\rm ref}Q_{10}^{(T_s-T_{\rm ref})/10}f_\theta(\theta_s)\) をサイトデータで推定。\(Q_{10}\) と \(f_\theta\) を普遍値として置かず、\(\rho_i\) は別の腐植化収率データなしに変えない |

ここで \(S(g;\theta_c,w_c)=[1+\exp(-(g-\theta_c)/w_c)]^{-1}\)。
この表の \(\phi\) 縮約は実装候補の概念式であり、既存文献の直接転記でも確立した
気象応答でもない。また \(\phi_0\) が非火災の背景転換だけを表すという識別も
まだないため、この分解自体を独立データで検証する。燃料水分 \(z\) を設ける場合、
枯死物 \(D_G\) は根由来も含むので
地表細燃料 \(F_{\rm fine}\) の代用とみなさない。必要なら独立プールを設計する。

## 5. 推奨する実装順序

### B0：単位のある気象変換だけを先に実装

独立な純関数 `saturation_vapor_pressure(T_c)` と
`air_vpd(T_c, rh_fraction)` を想定する。出力・入力単位をdocstringに書き、
\(T\in[0,50]\), \(R\in[0,1]\) を検証する。次を単体テストする：

- \(R=1\Rightarrow D_{\rm air}=0\)、\(R=0\Rightarrow D_{\rm air}=e_s(T)\)。
- 固定 \(T\) でRHが上がるとVPDが下がり、固定RHで \(T\) が上がるとVPDが上がる。
- kPa、°C、RH fraction/percentの取り違えを拒否する。
- 時間列を使う場合は各刻みの \(T,R\) から計算し、欠測・日平均化を明示する。

この変換だけでは植生応答を追加せず、既存の11状態平衡・炭素収支を変えない。

### B1：生産応答は計測可能なNPPへ一経路ずつ接続

優先データは対象地域での群別GPP/NPP、光、CO₂、葉温または気温、RH/VPD、
季節・土壌水分。C3/C4という分類だけで樹木/草本の数値係数を共有しない。
縮約フィットでは基準気象 \((T_0,R_0)\) で \(f_{i,\rm NPP}=1\) とし、正のNPP領域、
温度最適域と高温側の低下、VPD応答、観測範囲外の外挿制限を記録する。
係数が未推定なら関数を有効化せず、符号だけ制約した感度ケースとして別に表示する。

### B2：被覆応答は燃料水分・火災経由として別実験にする

第一候補の測定量は、火災時RH/T、地表細燃料の乾燥質量・含水率、焼失面積、
火線/燃焼強度、木本のサイズ別topkillと生残/萌芽、前後の被覆率。
燃料水分は乾量基準など定義した単位を持たせる。死細燃料の速い平衡応答と
生燃料・植物水分の季節応答を同一の状態にまとめない。

これらのデータで速い応答を支持できれば、観測時間刻みに応じた準平衡
\(z=z_{\rm eq}(T,R)\) を検討する。遅れが重要なら計画どおり
\[
\dot z=[z_{\rm eq}(T,R)-z]/\tau_z
\]
を追加し、\(\tau_z\) を燃料クラスの乾燥/湿潤観測から推定する。時間尺度が識別できない段階では
12状態化しない。湿度を燃焼率や \(\phi\) と同一視せず、発火・風・燃料量の背景条件を固定または明記する。

### B3：土壌炭素応答は土壌側 forcing が揃ってから

気温から土壌温度 \(T_s\) への伝熱遅れと、降水/土壌水収支から体積含水率
\(\theta_s\) への変換が必要である。相対湿度低下を \(\theta_s\) 低下として代入しない。
再湿潤パルスを扱うなら、土壌水分の時間変化・微生物過程を追加する別モデルとし、
現行の線形 \(k_D,k_H\) にRHの瞬時倍率を掛けない。

### B4：no-R条件を評価した後にのみ速度実験

採用した応答関数と範囲を固定してから、温暖化のみ（RH一定、従ってVPD変化）、
RH低下のみ（気温一定）、同時変化を区別する。同じ終点・経路で時間だけを変える。
経路全体で安定枝・不安定境界がどう動くかを解析し、計画の不変障壁条件を先に確認する。
成立すればno-Rを報告し、回避のためだけに競合応答や燃料水分状態を追加しない。
不成立でも、R-tippingの存在は数値軌道だけで確定しない。

## 6. 必須の出力・解釈上の制約

- \(T\) は気温、\(R\) は相対湿度、\(D_{\rm air}\) はVPD、\(\theta_s\) は土壌水分、
  \(z\) は燃料水分とし、単位と観測高さを併記する。
- GPP、NPP、\(R_a\)、\(R_h\)、炭素貯留変化は別々に保存する。NPPの定義に応じた
  \(R_a\) 処理を監査する。
- \(P_i,\alpha,\phi,k_D,k_H\) の基準条件・推定範囲・データ出典をmanifestに記録する。
- \(b_{ij}\) による転換放出と火災放出を混ぜず、火災後の地上部topkill、根生残、
  枯死物移行、燃焼排出を区分する。
- 各新規過程には純関数、手計算テスト、収支/境界テスト、単位・provenanceを追加し、
  native VISITの式でない縮約式には近似水準を付ける。

## 今回分かったこと／仮定／未解決点／次の一手

**分かったこと：** \(T,R\) から大気VPDは物理式で計算できる。生産には温度とVPDの
別機構があり、火災挙動にはCerradoで焼却時RHの効果を示す観測がある。苗木の乾燥・
火災応答も報告されるが、これらは現行 \(\alpha,\phi\) の年率を直接与えない。

**仮定：** 将来の reduced NPP response は基準気象で規格化する。燃料水分を追加する場合も、
まず独立した細燃料の定義と観測を必要条件とする。

**未解決点：** 対象サイト・機能型の \(P_T,P_G\) の温度/VPD応答、苗木から面積率への
\(\alpha\) の換算、気象・燃料から \(\phi\) への縮約、被覆モデル時間の年単位較正、
土壌温度・水分 forcing。

**次の一手：** B0の変換式・適用範囲をテスト可能な純関数として実装する前に、
観測可能性と使用データの解像度を確認する。その次に対象サイトの群別NPP/気孔応答を
特定し、推定できない係数は固定または未同定として残す。
