# VISIT配分の切替を導入した結果

詳細な式と導出は同名の temperature_nsc_allocation_branch_results.tex に記載した。
V4/V5の平衡分岐解析、V6の原式監査、V7の救済再配分対照まで進めた。
NSC不足に依存する枯死は全ケースで無効である。

## 主な結果

1. **従来のturnoverとVISIT配分を組み合わせると、正の平衡が存在しない。**
   10、15、20、25、30 ℃の各点で、炭素収支から得られる必要条件が破れる。
   目標から遠いと葉配分は5%で、葉の更新損失を補えない。
   目標近傍では葉配分は10%になるが、その葉量を維持するために必要な総投資がGPP上限を超える。
   非存在条件は動員速度に依存せず、非負の維持呼吸を使うV4/V5の双方に適用できる。
   この証明は正の平衡についてであり、周期軌道まで除外するものではない。

2. **TKY基礎turnoverに置き換えた対照では、目標葉量の面に滑り平衡候補が現れる。**
   5温度×3動員倍率×V4/V5の30条件で、切替面の両側から面へ向かう流れと、
   面内の局所安定な平衡候補を得た。通常の分岐内の根とは区別して保存した。
   TKYの基礎葉損失率は季節落葉を含まないため、この対照は落葉広葉樹の年平均モデルではない。

3. **V7の救済対照ではLAI=0.1の低葉量面に平衡候補が現れる。**
   原典どおり構造炭素を幹・根から葉へ移す。NSCを供給元に置き換えていない。
   これは従来turnoverのV4へ救済だけを追加した対照である。
   上記の高葉量候補とはモデル設定が異なるため、健全・不健全の共存を検出したことにはならない。

4. **V6を直接転記する際の問題が明確になった。**
   原典では幹配分で貯蔵容量を超えた後、根配分の行先を再判定する。
   また貯蔵に振り向けても成長呼吸は構造量から引く。
   小さな構造量を与える監査入力では負在庫になる場合がある。
   実際のTKY時系列で負在庫が生じたという結果ではない。
   今回の非負性・NSC不足による構造損失を外す要件に合わせるには、
   貯蔵を優先する際の実動員と成長呼吸を連動させる別の保存的な規則が必要である。

## 数学的な整理

総NSC動員を $V=\sum_i\kappa_iN_i$、葉配分を $c_f$、構造収率を $y$、
器官損失率を $\ell_i$ とする。固定配分の分岐内では
$C_i=yc_iV/\ell_i$ で構造量を消去できる。
幹・根NSCは二次方程式の非負根、葉NSCは総動員の定義から決まり、
残る平衡式は総動員Vの1変数方程式になる。
求めた根を元の分岐条件へ代入し、条件外の根は棄却する。

定常植物収支は $G=V+\sum R_i+\sum\ell_iN_i\ge V$ となる。
GPPの原点傾きを $g_0$、上限を $G_{\max}$ とすれば、
遠い分岐で $0.05yg_0/\ell_L<1$、
近い分岐で $G_{\max}<\ell_LC_*/[a_f(y+\ell_L\Delta t_{\rm ref})]$
が成立すると、正の平衡は存在しない。
今回の従来turnoverでは両条件が全5温度点で成立した。
基準時間1日はモデル定義であり、積分刻みを変えても変えない。

切替面の両側の場を凸結合し、面に垂直な速度がゼロになる組合せを用いると、
面内の流れを定義できる。今回の「滑り平衡候補」はこの解釈による。
日次写像や平滑化幅を縮めるモデルで同じ吸引対象が得られるかは未検証である。
滑り平衡もこの解釈のQSE候補に当たるため、存在だけで「QSE以外への吸引」を示したことにはならない。

## 出典と仮定

原典は Sachitama2001/VISIT-matrix、commit 3285bd8e131a932e338b59892751648fd9edcc7b。
配分は allocation.c:25–77、救済は同125–154、
容量は ecophysiology.c:77–87、貯蔵更新は plant_proc.c:209–233。
今回、配分・最適LAI・GPPは原C関数をコンパイルしたハーネスと直接比較した。
最適LAI・GPPの比較は同じ生理中間値を与えた代数式の比較であり、
気孔と細胞内CO₂の反復を含む全過程の比較ではない。

NSC動員 (0.03, 0.001, 0.003) day⁻¹ は従来モデルの数値から設定した探索仮定であり、
VISIT由来係数ではない。0.1、1、10倍を独立比較する。
固定PPFD・日長・細胞内CO₂も前段の仮定を継承している。
計画書が求める参照日データによる確定は未完であり、TKYの定量予測としては解釈しない。
最適LAI式の呼吸中間量の次元解釈も未解決として残した。

## 実行と成果物

    python examples/run_nsc_allocation_audit.py --config configs/temperature_nsc_allocation_v4.json
    python examples/summarize_nsc_allocation.py artifacts/temperature_nsc_visit_allocation/v4_v5_v7_branch_audit_v4

出力先は同名の成果物ディレクトリ。既存のV0–V3結果は上書きしていない。
同じ出力先への再実行は拒否するので、再実行時は --output で新しいディレクトリを指定する。

- frozen.json：分岐内根・採否・切替面候補・裸地侵入固有値・非存在条件
- rescue.json：V7救済対照の低葉量切替面
- trajectories.json と各NPZ：最大2000年の固定温度積分・非負性・収支・刻み比較
- audited_summary.json：検証集計
- comparison.pdf/png：非存在条件、切替面候補、固定温度の時系列
- source_snapshot/、manifest.json：実行時ソースと設定、元配分コード、TKY表、ハッシュ

最初のv2（最大刻み30日）は計算時間のため途中で停止した。
続くv3では、極小葉量でGPPが桁落ちしてゼロになり、数値領域境界へ早く到達する誤差を検出した。
平方根差を有理化し、expm1/log1pで代数的に等価な式を評価するよう修正した。
葉量10⁻¹⁰⁰まで原点傾きを保持することをテストした。v2/v3の部分結果は検証記録のみとして残す。
修正後のv4は固定環境の適応積分で最大刻みを365日とし、代表6条件を182.5日・厳しい許容誤差と比較する。
イベント終端時刻の差を共通年次標本の比較に混ぜない。

修正後の36本では28本が植物総量10⁻¹² Mg C ha⁻¹の停止基準に到達した。
残り8本は葉・NSCの対数在庫が−600に達し、安全停止した。
その時点の植物総量は約2×10⁻¹²～1.5×10⁻¹⁰ Mg C ha⁻¹であり、
主に減衰の遅い幹炭素が残る。桁落ちを直しても、葉・NSCと幹の減衰速度差から
生じる数値表現の限界は残る。この8本をスピンアップ収束済みとは判定しない。

## 次の優先順位

1. 目標葉量・救済閾値での滑り、平滑化、1日写像の対応を調べる。
2. 固定気象と細胞内CO₂の参照値、季節落葉を含めた年平均損失の意味を確定する。
3. 保存的なV6を追加し、同じ設定内の吸引対象と境界を解析する。
4. 多安定性または別の吸引対象が確認できた場合に、同一温度経路の速度実験へ進む。

現段階ではR-tippingを実証していない。平衡がない・切替面に吸引される・
長い過渡がある、という三つを区別できたことが今回の到達点である。
