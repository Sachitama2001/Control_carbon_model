# 温度・降水実験：第一段階の結果

2026-09-22。研究計画の WP1 を実装・検証し、WP2 の単独強制、4実験比較、
枯死階層の比較を実行した。WP2 の機構分離には下記の未解決点がある。
WP3 の二次元分岐解析、WP4 の速度族、WP5 の生態学的パラメータ制約は未実施である。

## 得られた結果

**この8状態モデルの仮定値では、複合効果は非加算的になり、その符号は観察する
時間によって変わった。R-tippingはまだ示していない。**

基準気象は27 °C、6 mm/day、昇温後は31 °C。
降水は4 mm/dayと2 mm/dayの二通りを実行した。
気象を実験開始時に切り替え、その後一定に保持する。
一定入力は月別区分一定入力の特殊な場合であり、季節実験ではない。
各枯死階層の初期状態は、その階層自身の基準気象で求めた結合平衡である。
異なる階層間の差には基準平衡の差も含まれる。

6→4 mm/dayでは土壌水が圃場容水量より多いため、相対土壌水分が1に留まり、
降水減少の炭素応答は数値誤差の範囲でゼロだった。
例えば枯死なしでは土壌水が306.634→274.768 mmに変わるが、圃場容水量は240 mm。
これは設定した水分応答関数の飽和に由来する。降水が常に炭素量へ影響すると
決めつけない対照として保存した。

単独降水の継続計算で水分制限が作動する2 mm/dayを追加したところ、
炭素応答と相互作用が現れた。枯死なしの土壌水平衡は137.018 mmになった。
枯死係数を調整してtippingを発生させる探索はしていない。

`I_C=C_TP-C_T-C_P+C_0` とする。以下は **平衡での全炭素**、単位は Mg C/ha。

| 枯死の追加 | 基準 0 | 温度 T | 降水 P | 複合 TP | 平衡 I_C | 20年後 I_C |
|---|---:|---:|---:|---:|---:|---:|
| なし（通常ターンオーバーはあり） | 598.804 | 399.854 | 430.150 | 242.007 | +10.807 | +3.032 |
| 温度依存 | 592.453 | 350.346 | 426.283 | 217.570 | +33.393 | +9.241 |
| 水分依存 | 596.430 | 397.608 | 350.976 | 189.569 | +37.416 | −9.901 |
| 温度＋水分、加算 | 590.231 | 349.315 | 350.626 | 187.432 | +77.721 | +8.794 |

正の I_C は、今回のように両単独実験が炭素を減らす場合、減少が単独効果の和より
小さいことを意味する。「複合で最大の減少」と「減少の相乗的な増幅」は同じではない。
明示的な積の枯死項は、どの実験にも含めていない。

### 20年と200年で結論が変わる例

水分依存枯死のケースを200年間保持した。相互作用は約33.10–33.13年の間に
負から正へ変わり、200年後は+37.380 Mg C/haとなった。
別途計算した平衡値+37.416へ近づいている。
200年後の全8状態の平衡からの最大規格化距離は、4実験を通じて7.67e-5以下。
基準の最も遅い線形緩和時間は約24.6年である。

この例は、有限期間の複合効果が平衡効果と逆符号になり得ることを示す。
速度族や吸引域境界は調べていないため、R-tippingや別の吸引状態への転換を
意味しない。長い過渡応答を区別するための対照実験として有用である。

## 実装と仕様上の判断

新しい独立モジュールは `src/control_carbon/temperature_precipitation.py`。
既存のVISIT実行・xlsx、水ポテンシャル輸送モデルとは別の理論モデルである。
炭素・水は葉／幹／根／土壌の各4区画、時刻の単位は日。

- 純粋フラックス関数、炭素行列、炭素capacity、結合平衡、8×8ヤコビアンを実装。
- 月降水量→日フラックスは実際の暦月長で換算し、区分一定月入力は月境界で積分を分割。
- 内部輸送は相対水分差の非負C1関数。Darcy流そのものとは呼ばない。
- 呼吸に伴う炭素・水容量減少を明示的な水放出に含め、動く容量上限を維持。
- 土壌飽和時は降水・植物からの還流を明示的な表面流出へ回す。
- 解の事後clippingを行わず、非負性と容量上限を検査。

式・符号・事前閾値は [実装仕様](temperature_precipitation_implementation.md)、
数式を通して読める形は [TeXレポート](temperature_precipitation_first_results.tex) に記載した。
閲覧用の [PDF](../artifacts/temperature_precipitation/report/temperature_precipitation_first_results.pdf) も生成した。
全パラメータは検証用の仮定値。単位・出典区分・値を各出力先の `parameters.csv` と
`manifest.json` に保存した。生態学的範囲は不明のまま明記し、WP5へ残してある。

## 平衡と安定性の検査範囲

各枯死階層について、T=27–33 °C（0.5 °C刻み、P=6固定）、
P=6–2 mm/day（1/3 mm/day刻み、T=27固定）の正の枝をパラメータ継続し、
往復の一致を確認した。52点/階層（逆向きの重複を含む）、計208点。
これは自然パラメータ継続であり、foldを通過できる擬似弧長継続ではない。
全採用点で固有値の最大実部は負。16個の乾燥比較の4実験端点も安定だった。

「正の安定枝が見つかった」と「安定平衡が一つしかない」は異なる。
ゼロ炭素境界、他の平衡枝、不安定平衡、吸引域はまだ網羅していない。
したがってH0の一意性や、領域全体でtippingがないことを証明したとはしない。

## 機構分離で見つかった問題

熱枯死だけを基準値に固定する実験と、光合成・呼吸・熱枯死の温度をすべて
基準値に固定して蒸発散の温度効果だけを残す実験は、別々に実装した。
水分枯死率を初期値で固定する比較も保存した。

一方、計画にある「絶対水量Wを基準値へ固定」は、炭素が減少して水保持容量が
縮小すると物理領域を出た。最初の違反が保存値で見つかったのは670–1050日で、
最大超過水は0.35–2.22 mmだった。これは自然な8状態系の問題ではなく、
その介入の問題である。`audit.json` に不合格と明記し、違反後の値を生態学的な
機構帰属には採用しない。図・CSVには失敗診断として残している。

次は、(a)絶対水量と容量を共に固定する介入、(b)相対水分を固定する介入、
のどちらが知りたい因果効果に適合するかを式で整理する必要がある。
状態数を増やせば解決する問題ではない。

## 数値検証

- 全体テスト：176 passed、7 skipped。今回の専用テストは13件。
- 32本の20年4実験における最大収支残差：C 5.56e-17 Mg C/ha/day、W 1.07e-15 mm/day以下。
- 乾燥比較の端点平衡残差：最大2.80e-14（各状態の右辺の単位）。
- 通常の8状態軌跡の非負性・容量違反：検出なし。
- Radau（最大10日）対 BDF（最大5日・厳しい許容誤差）の最大規格化差：2.41e-8以下。
- 200年TP軌跡の同じ比較：7.54e-9以下。
- ヤコビアンの差分刻み細分化、C→WとW→Cの結合、手計算極限、月長・月境界もテスト。

炭素赤字と高温・乾燥doseは保存点での台形積分である（通常5日、長期保持10日）。
これは厳密な積分器内の求積ではない。将来のrate/dose比較の際は求積細分化も必要。
非適用の回復時間（基準へ戻すパルス未実施）を捏造せず、平衡固有値の緩和時間と区別する。

## 再現方法と成果物

リポジトリ直下で実行する。

```bash
PYTHONPATH=src python examples/run_temperature_precipitation.py
PYTHONPATH=src python examples/run_temperature_precipitation.py \
  --precipitation-end 2 --output artifacts/temperature_precipitation/wp1_wp2_dry
PYTHONPATH=src python examples/check_temperature_precipitation_long_hold.py
PYTHONPATH=src python examples/audit_temperature_precipitation.py
PYTHONPATH=src pytest -q tests/test_temperature_precipitation.py
TEXMFVAR=/tmp/control-carbon-tex-cache lualatex -interaction=nonstopmode \
  -halt-on-error -output-directory=artifacts/temperature_precipitation/report \
  docs/temperature_precipitation_first_results.tex
```

- `artifacts/temperature_precipitation/wp1_wp2/`：4 mm/dayの対照。
- `artifacts/temperature_precipitation/wp1_wp2_dry/`：2 mm/dayの比較。
- `artifacts/temperature_precipitation/long_hold/`：水分依存枯死の200年保持。
- 各場所のCSV/NPZ：全状態、外部・内部フラックス、枯死、NEP、capacity、dose。
- `equilibria.csv`、`single_driver_continuation.csv`：平衡、固有値、残差、条件数。
- PNG/PDF：時間応答、8状態軌道の2次元投影、単独強制の枝、介入比較。
- `manifest.json`：パラメータ区分、solver、閾値、git commit、ソースSHA-256。
- `audit.json`：保存されたJacobian・固有値の整合、ソース一致、固定水量介入の不合格。
