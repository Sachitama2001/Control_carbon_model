# VISIT 説明スライドの R-tipping 過程選別

詳細は [TeX](visit_r_tipping_process_screening.tex) / [PDF](visit_r_tipping_process_screening.pdf) を参照。

## 結論

- スライド19--28の光合成、気孔、呼吸、土壌分解の各診断式は、単独では通常、状態記憶も複数の吸引域も作らない。
- 第一候補は、葉炭素 → LAI → GPP → 葉への配分 → 葉炭素という閉ループである。区分的配分と非構造性炭素（NSC）が閾値と記憶を与え得る。
- 温度、VPD、土壌水分、葉窒素は、既存の吸引域境界を動かす制御変数の候補である。
- FvCB の律速枝、気孔の代数根、凍結閾値の切替えだけを R-tipping と呼ぶことはできない。
- `visit_ex_2020.pptx` は説明資料であり、固定版ソースの実行式と同一ではない。固定版 `plant_proc.c:132-138` は Monsi--Saeki 型の日 GPP を選び、DePury--Farquhar 呼出しはコメントアウトしている。
- 現段階は候補抽出であり、VISIT に R-tipping が存在するという実証ではない。

## 次の検証

固定版ソースの日次更新順序を保存した植物写像を完成し、一定環境または一年周期環境について、多初期値固定点探索、安定性、吸引域、環境ランプ速度を順に調べる。最初に動かす候補は最適 LAI、温度、土壌水分または VPD である。
