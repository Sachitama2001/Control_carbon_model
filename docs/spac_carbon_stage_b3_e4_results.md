# Stage B3：通常VPD範囲でのE4非線形分岐と仮説感度

2026-10-13。[単位・尺度の見直し](spac_carbon_units_and_scales.md)を引き継ぐ、
限定した次段階の結果。**合成モデルの局所数学解析であり、森林死亡・
真のR-tipping・観測閾値の報告ではない。**

## 1. なぜこの課題を先に選んだか

[研究の論理報告](spac_carbon_research_logic_report.md)では、
E3の不安定周期解と回復/退出境界をつなぐ大域解析を次の候補とした。
しかしその後の単位整理で、E2/E3のHopfは25℃の飽和水蒸気圧を超える
形式的高VPD域にあると分かった。一方、木部feedbackを含むE4の振動候補は
VPD約0.002665 MPaで、指定された通常範囲0～0.003 MPa内にある。

そこで今回は、**E3の大域追跡より、E4候補の局所型と係数感度を優先**した。
以前の結論を取り消すのではなく、主気象範囲で先に検証すべき問いを変えた。
「通常範囲内」というだけで生理的妥当性が保証されるわけではない。

問いは次の順に限定した：

1. E4の振動候補は非退化Hopfと数値的に確認できるか。
2. そこに生じる周期解は安定か、不安定か。
3. 合成の容量・木部倍率・木部損失を変えると結論はどこまで維持されるか。

退出後の生理モデル、臨界速度、大域安定多様体は今回追加していない。

## 2. 仮定・単位・保全したもの

- 外力VPDは正の蒸気圧差、MPa。大気の水ポテンシャルではない。
- 気圧0.101325 MPaを明示し、内部の原著変数D＝VPD/気圧へ換算。
- 25℃は湿度整合性の診断だけに使用。新しい温度応答は入れていない。
- 状態・時間は元のMPa、kg C/m² ground、day。
- 正平衡から一度決めたL_ref/W_refは感度ケースでも固定する。
- 基本E4はF_L、F_E、F_Wを全て有効、木部指数β_W＝1。
- 基本方程式、合成設定、Stage A/B1のコード・過去成果物は保全。
  B2の第一Lyapunov係数の計算helperだけを3×3から4×4にも使えるよう一般化し、
  既存B2・MPa回帰で同じ挙動を確認した。

## 3. 演繹：E4では4状態を残す必要がある

E4ではWが水理へ戻るため、E2/E3の3状態系への切り詰めはできない。
能動状態は \((\psi_x,\psi_l,L,W)\)、受動状態はR/Sである。
式の依存関係から、全Jacobianの特性多項式は厳密に
\[
\det(\lambda I_6-J)
=(\lambda+k_R)(\lambda+k_S)\det(\lambda I_4-A_4)
\]
と分解できる。**水理やWを瞬時平衡に置く近似ではない。**

単位整理の段階で、この4次多項式のHurwitz境界と複素対の横断は点検済みだった。
今回はさらに、4状態の2階・3階微分を有限Leibniz則で解析的に構成した。
木部倍率 \(F_W=(W/W_{\rm ref})^{\beta_W}\) の高階微分も含め、
β_W＝0.5/1/2でJacobian・2階テンソルの中央差分と一致することを検証した。

実装：[E4局所解析](../src/control_carbon/spac_carbon_e4.py)。
入力境界は既存の[PressureSPAC](../src/control_carbon/spac_carbon_mpa.py)を使用。

## 4. 数値評価：候補はsubcritical Hopf

解析テンソルから、B2と同じKuznetsov規約で第一Lyapunov係数を計算。
臨界固有ベクトルqは元の4状態座標で‖q‖₂＝1、
左固有ベクトルpは〈p,q〉＝1。l1の**符号**が局所型を決め、
大きさは座標・規格化に依存する。E3との数値の大小を生理的強さとして比較しない。

| 指標 | 基本E4の値 |
|---|---:|
| Hopf VPD | 0.002664752905 MPa |
| 25℃の診断RH | 約0.158718 |
| 臨界角周波数ω | 0.02221938703 day⁻¹ |
| 第一Lyapunov係数l1 | **+39.69534297** |
| d Re(λ)/dVPD | +419.8689748 day⁻¹/MPa |
| 他の能動固有値 | −2.58300821、−1.85896382e−5 day⁻¹ |

単純共役対、非零周波数、非零の横断性、非零l1を確認。
他の2本は安定だが、一方は非常に遅い木部結合モードである。
R/Sの追加固有値も負である。
横断性は葉ポテンシャル差分幅1e−5/5e−6、l1はテンソルの差分幅
1e−4/5e−5で再評価して一致した。

従って、**数値的に検証した局所型はsubcritical Hopf**：
VPDが閾値より小さい安定平衡側に、小振幅の不安定周期解が現れる。
Hopf根とl1の区間認証は未実施なので、厳密な計算機援用存在証明とは区別する。

## 5. なぜ今回は周期境界値collocationを使ったか

B2では不安定周期解をshootingで求めた。E4にはさらに遅い能動Wモードがある。
今回は独立した確認方法として、**一周の軌道全体を同時に求める周期境界値問題**
を解いた。複数の時点で微分方程式を満たすよう補正するcollocation法である。

未知量は4状態の周期関数・周期T・VPD。
4本の周期境界条件に位相条件と非零振幅条件を加える。
振幅を固定するため、solverが平衡点を「周期解」として返す偽収束を除外できる。
通常の長時間前進積分で、不安定軌道上に留まることを期待する手法ではない。

R/Sは能動4状態から駆動される線形系の一意な周期応答を解いて復元。
全6状態で正の炭素・周期閉鎖・水/炭素収支を検査した。
さらにcollocation軌道から独立した前進IVPを一周期解き、軌道の一致を確認した。
周期解の安定性は変分方程式のFloquet乗数で判定する。

| 振幅座標r | VPD（MPa） | 周期（day） | 径方向Floquet乗数 |
|---:|---:|---:|---:|
| 0.0005 | 0.002664752380 | 282.790448 | 1.00012254 |
| 0.001 | 0.002664750803 | 282.823565 | 1.00046752 |
| 0.002 | 0.002664744480 | 282.956473 | 1.00163422 |

全て基本Hopf値より低いVPD側にあり、径方向乗数>1。
中立乗数は1、残りの乗数は絶対値<1で、**周期解は吸引子ではない**。
振幅rは臨界モードの座標であって、炭素質量の直接の単位ではない。

精度確認：

- collocation許容誤差1e−9→1e−10で、VPD差<2.5e−17 MPa、
  周期差<1.9e−7 day、同位相状態差<3.7e−12。
- 径方向乗数差<1.7e−8で、乗数の1からの差より十分小さい。
- 基本3軌道の独立IVPとの差<1.6e−11、閉鎖残差<4.5e−16。
- 水・炭素収支残差<1e−19。

これらは精度・整合性の検査であり、大域境界の証明ではない。

## 6. 7ケースの限定感度：どこまで頑健か

後付けでtippingを得る係数探索はせず、基本＋事前に限定した6変更だけを比較した。
容量はCx/Clを同倍率、木部損失はk_Wだけを変更。
参照炭素量を再計算しないので、損失変更ケースの基準気象下の平衡は元の参照と異なり得る。

| 変更 | 複素対の横断VPD（MPa） | 判定 |
|---|---:|---|
| 基本 | 0.002664753 | subcritical Hopf |
| 容量×0.5 | 0.002664603 | 同型、主解析内 |
| 容量×2 | 0.002665054 | 同型、主解析内 |
| 木部指数0.75 | 0.003320495 | 同型だが25℃湿度条件の範囲外 |
| 木部指数1.25 | 0.002030994 | **既に実固有値が正の枝上の複素対横断** |
| 木部損失×0.5 | 0.003647514 | subcritical型だが25℃湿度条件の範囲外 |
| 木部損失×2 | 0.001731758 | subcritical型、主解析内 |

木部指数1.25では、検出されたfoldがVPD≈0.002128793 MPaにある。
複素対横断地点には他の不安定実固有値約+2.11e−5/dayがある。
従って、基本モデルと同じ「安定平衡がHopfで不安定になる」現象として扱わない。
そのケースのl1や周期解は今回の安定側Hopf解析の対象外として、未評価を明示した。
鞍点上のHopfが不可能という主張ではない。

**結論：容量の限定変更には今回の型が維持されたが、
木部炭素を供給能力へ写す仮説と木部損失は、気象範囲・分岐構造の解釈を変える。**
一般的な頑健性定理や較正済みの生理閾値とは言えない。
