# Stage B2：安定性・振動分岐・植生領域の短期計画

2026-10-12。出発点は[Stage B1結果](spac_carbon_stage_b_results.md)、
基準コミット `05a7609`。Stage A/B1、合成係数、6状態、水・炭素収支を保全する。
VISIT再現・森林死亡・真のR-tippingを先取りして主張しない。

## 目的と作業順

1. **経路全体の凍結安定性**
   - 木部feedbackなしのE2/E3では、能動的な水理2状態＋葉炭素の3状態と、
     受動的なW/R/Sの安定固有値へ厳密に分解する。
   - 特性多項式のRouth–Hurwitz条件を導出し、D＝0.01～0.03を覆う
     平衡枝を区間計算で検証する。節点走査を連続区間の証明と呼ばない。
   - 平衡枝の一意性・存続と、非自律軌道の追跡/no-Rは区別する。
2. **振動的候補の非線形解析**
   - まずE2/E3の既検出候補だけを対象とし、解析的な2階・3階微分、
     固有値横断性、第一Lyapunov係数を計算する。
   - Hopfの局所型を判定し、可能なら近傍周期解をshootingと
     Floquet乗数で確認する。有限差分・許容誤差・時間刻みの精度を照合する。
   - E4の4能動状態への拡張、大域周期解追跡、臨界速度探索は後続に回す。
3. **植生領域退出後の定義**
   - L→0の形式的極限と非通水continuum、固定容量の限界、
     組織量依存貯留の保存則を整理する。
   - 退出後を扱うために必要な状態・流束・根拠を明記する。
     根拠未確定の死亡レジーム・残留conductance・復活入力は追加しない。
     生理仮説の選択が必要になれば、独立variant導入前に相談する。

## 最初の区切りと受入条件

- 独立解析コード、ターゲットテスト、再現runner、日本語結果報告を残す。
- 3状態ブロックの固有値が全6×6と一致し、解析微分が既存Jacobianと
  中央差分に一致する。Hurwitz判定は安定・不安定両方で照合する。
- 区間検証は入力・丸め方向・被覆区間・証明できなかったセルを明示する。
- Hopf判定は単純共役対・非零周波数・横断性・非零Lyapunov係数を確認する。
  周期解を主張する場合は平衡への偽収束を除外し、周期・残差・乗数を保存する。
- 元の実験を上書きせず、全係数を合成仮説と明示し、ソースhashを記録する。
- 局所Hopf、凍結安定性、速度依存の領域退出、別吸引先へのR-tippingを
  混同しない。今回の最初の区切りは前二者と退出後の要件整理まで。
