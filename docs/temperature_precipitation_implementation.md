## 方程式を閉じる補足

時間は day、C は Mg C/ha、W は地表面積当たり mm。
炭素式と GPP・温度・水分・枯死関数は研究計画 §6–8 に従う。
係数はすべて検証用の仮定値であり、VISITから転用した値やAmazonでの校正値ではない。

内部輸送は `g * phi(r_donor-r_receiver)`、
`phi(z) = max(z,0)^2 / (max(z,0)+delta)` とする。
この C1 関数は逆勾配でゼロとなり、乾いた供与区画からの流出を防ぐ。
土壌の相対水分だけは [0,1] の範囲に制限して関数へ渡す。
これは水量の事後補正ではなく、土壌が圃場容水量を超える領域の応答定義である。

植物の容量 `omega*C+epsilon` の縮小には維持呼吸も寄与する。
そのため第一実装では `L_i^W=(tau_i+m_i+r_i0*q_R)*W_i` とし、
研究計画の候補 `(tau_i+m_i)*W_i` に呼吸に伴う容量縮小分を追加する。
`W_i=cap_i` では内部流入がゼロなので、
`d(cap_i-W_i)/dt >= omega_i*a_i*G + loss_i*epsilon_i >= 0`。
この規則は水の消失ではなく明示的な放出であり、zeta の割合で土壌へ戻す。
呼吸が構造Cを直接減らす本計画に対応した仮定である。

土壌飽和容量 W_sat を追加し、植物からの還流込みの供給を
`I=P+sum(zeta_i*L_i^W)`、表面流出を `Q=I*(W_O/W_sat)^n_Q` とする。
`W_O=W_sat` で供給分をすべて表面流出に回す。
深部排水は `D=k_D*max(W_O-W_fc,0)`。従って上限を事後clippingせず保持できる。
この表面流出と水放出の閉包は本実装で定義した仮定で、原典由来の式とは呼ばない。

## 事前の合格閾値

- 炭素・水の瞬間収支残差：絶対値 1e-10 以下（それぞれのフラックス単位）。
- 基準平衡：各状態の右辺の絶対値最大 1e-8 以下。
- 安定性：最大固有値実部 < -1e-8 /day。
- 非負境界、植物容量境界、土壌飽和境界でベクトル場が外向きでない。
- 数値解の非負性・容量違反：1e-6（各状態の単位）以下。
- 最大内部刻み 10 day と 5 day、異なるsolverの同時刻状態差：
  `max(abs(delta x)/max(1,abs(x_reference))) < 1e-5`。

## 実験の区切り

まず定常入力、通常ターンオーバーのみで実装を検証する。
その後、温度枯死、水分枯死、加算枯死を順に実験する。
明示的な相互作用枯死、季節周期、速度族、状態追加はこの区切りに含めない。
単独強制の継続計算は正の生存枝を局所的に追う。全平衡の網羅や一意性の証明ではない。

clamp実験では温度の光合成・呼吸・熱枯死・蒸発散を別々に固定できる。
熱枯死のみを固定しても蒸発散だけの温度効果にはならない。
水状態を固定する比較は4炭素状態の介入モデルであり、全8状態の水収支実験とは区別する。
