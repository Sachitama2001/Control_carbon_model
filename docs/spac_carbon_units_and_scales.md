# SPAC–炭素モデル：単位系と探索スケールの見直し

2026-10-13。まず単位と探索範囲を整え、次段階としてE4の局所安定性を小さく点検した。
**方程式・合成係数・固定参照炭素量は変更していない。実測への較正ではない。**

## 1. 今後のVPDはMPaで扱う

利用者確認により、VPDは**正の蒸気圧差のまま**、現在の解析用の入力・出力・図をMPaに統一する。
水ポテンシャルは従来どおりMPa、通常は非正。両者の単位が同じでも、
**VPDを大気の水ポテンシャルに置き換えたわけではない**。

原著再現の内部変数を \(D\)（mol/mol）、圧力表示のVPDを \(v\)（MPa）とすると、

\[
 D=\frac{v}{p_{\rm atm}},\qquad
 E=g_s F_E D=\underbrace{\frac{g_s}{p_{\rm atm}}}_{g_{s,\rm MPa}}F_E v.
\]

今回の明示的な仮定は \(p_{\rm atm}=0.101325\) MPa。
既存の \(g_{s,\max}=0.47\) m水/dayは、圧力表示では
\(g_{s,\max,\rm MPa}=4.63853935\) m水/day/MPaとなる。
係数を換算せずにVPDの数値だけMPaへ置き換えると、蒸散量が変わってしまう。
今回は境界で \(v/p_{\rm atm}\) を計算し、元の式へ渡すことでそれを防いだ。

| 量 | 現在の単位・扱い |
|---|---|
| 根・木部・葉の水ポテンシャル | MPa |
| 利用者向けVPD | MPa、非負 |
| 大気圧 | MPa、有限かつ正、解析モデル作成時に必須 |
| 水フラックス | m水/day/地表面積 |
| 水理コンダクタンス \(g_x\) | m水/day/MPa |
| 圧力表示の蒸散係数 \(g_{s,\rm MPa}\) | m水/day/MPa |
| 水容量 \(C_x,C_l\) | m水/MPa/地表面積 |
| 葉・木部・根・土壌炭素 | kg C/m²地表面積 |
| 時間・固有値 | day、day⁻¹ |
| 炭素速度係数 | 設定のyear⁻¹を365.25 day/yearでday⁻¹に換算 |
| SLA・葉面積指数 | m²葉/kg乾物、LAIは無次元 |

新しい入口は [PressureSPAC](../src/control_carbon/spac_carbon_mpa.py) と
[MPa設定](../configs/spac_carbon_pressure_review.json)。
RHS、フラックス、Jacobian、平衡点、枝の勾配、continuation、時変外力、
Hopf、shooting、連続経路の区間証明まで同じ換算を用いる。
原著の再現API・旧Stage A/B1/B2 runner・旧設定・旧成果物は、
**mol/molの履歴再現用**として保全した。古い`D`へMPa値を直接渡してはいけない。
新しい解析にはMPaの入口を使う。E0は既存Stage Aと同じ正植生領域の一方向結合を含むが、
Stage Aの温度実験・sigmoid拡張などをこの入口へ移植したわけではない。

表示量だけでなく、微分とアルゴリズムの尺度にも換算が必要である：

\[
 \frac{dv}{d\psi_l}=p_{\rm atm}\frac{dD}{d\psi_l},\qquad
 \frac{d\,\mathrm{Re}\lambda}{dv}
 =\frac{1}{p_{\rm atm}}\frac{d\,\mathrm{Re}\lambda}{dD},
 \qquad \delta v=p_{\rm atm}\delta D.
\]

continuationの旧尺度0.02は0.0020265 MPaへ対応する。
状態変数・時間を変えていないので、固有値、第一Lyapunov係数、
周期、Floquet乗数は変わらない。l1の数値は元の状態座標と正規化に依存する量であり、
普遍的な物理定数ではない。

区間証明ではMPa端点を単なるbinary64除算で変換せず、
元のbinary64定数を厳密実数と解釈し、40桁Decimalで外向きに除算する。
証明結果の圧力区間・勾配も外向きに乗算する。丸めで対象区間を縮めていない。

## 2. 主解析と形式的探索を分ける

確認済みの出発設定：

- 気圧：0.101325 MPa。
- 気温：25℃。**VPDと相対湿度の整合性診断のみ**に使う。
- 主解析VPD：0～0.003 MPa（0～3 kPa）。
- 形式的な比較図：0～0.02 MPa。主解析の気象外力とは区別する。
- 既存の比較経路：0.00101325→0.00303975 MPa。元の実験をそのまま換算し、
  終点を新しい主解析上限へ黙って切り下げない。

[既存のTetens実装](../src/control_carbon/visitc_hydrology.py)のhPa出力をMPaへ換算すると、
25℃の飽和水蒸気圧は \(e_s\simeq0.0031674893\) MPa。
これを用いて

\[
 RH=1-\frac{v}{e_s(T)}
\]

を診断する。25℃、相対湿度0～1では \(0\le v\le e_s\)。
主解析の上限0.003 MPaはRH約5.29%に相当し、**かなり乾燥した端まで含む**。
「一般的な気候の典型値」や普遍的な上限として選んだのではない。
既存経路の終点はRH約4.03%で、主解析上限を僅かに超えるが25℃の物理的範囲内。

| 合成モデルの境界 | VPD（MPa） | 参考：kPa | 主解析内 | 25℃での整合性 |
|---|---:|---:|---|---|
| E0 fold | 0.002472043 | 2.472 | はい | RH約22.0% |
| E1 fold | 0.001546784 | 1.547 | はい | RH約51.2% |
| E2 subcritical Hopf | 0.015337756 | 15.338 | いいえ | RH<0：25℃では不可能 |
| E3 subcritical Hopf | 0.004863191 | 4.863 | いいえ | RH<0：25℃では不可能 |
| E4 振動的不安定化候補 | 0.002664753 | 2.665 | はい | RH約15.9% |

**ここが今回の重要な整理である。**
E2/E3のHopfと不安定周期解は、合成系の数学的性質として残る。
しかし、25℃の通常探索の主要現象として紹介するのは不適切だった。
温度を上げれば許容VPDは変わるが、実際の温度変更では光合成・呼吸なども変わり得る。
今回はその温度応答を追加せず、整合性診断だけを行った。
ここに示す閾値は気圧仮定と未較正の合成係数に依存し、観測された森林死亡閾値ではない。

## 3. 水理・炭素の値と時間スケール

| 合成設定／診断 | 値 | 解釈・注意 |
|---|---:|---|
| 水理 \(g_{x,\max}\) | 0.0086 m水/day/MPa | 元の係数を保全 |
| \(C_x=C_l\) | 0.001 m水/MPa | 各1 mm水/MPa。原著への較正値ではない |
| 脆弱性半減ポテンシャル | −1.5、−2.0 MPa | VPDと符号・物理的意味が違う |
| 固定参照 \(L,W,R,S\) | 0.2982、6.3614、1.1928、16.1022 kg C/m² | 元の平衡から一度だけ計算した値 |
| 参照LAI | 約5.964 | SLA=10、炭素乾物比=0.5から算出 |
| 炭素損失の時定数 | 葉1.25、木部20、根5、土壌25 year | 単独損失の逆数。結合系の固有時定数ではない |
| 参照E0の水理局所減衰時定数 | 約0.02762、0.20207 day | 約0.66、4.85時間。植生平衡の全モードではない |
| 葉floor、葉の領域境界 | 0.01、0.000001 kg C/m² | 正則化と計算領域の仮定。死亡閾値ではない |

水理は時間単位、炭素は年単位という大きな尺度差がある。
Radauを使う理由はこの剛性にもあり、day/yearの混同が原因ではない。
VPDは概ね10⁻³ MPa、植物の水ポテンシャルは概ね10⁰ MPaという差も自然に残る。
**単位を揃えることは、同じ数値の大きさへ正規化することではない。**

炭素量、LAI、水容量、floor、損失係数を今回同時に再調整すると、
単位修正と物理的モデル変更を区別できなくなる。そのため係数は保全し、
今後の較正対象として明示した。根ポテンシャル0 MPaの固定外力も、
降水・土壌水分・根圏動態を表したものではない。

## 5. 次段階への小さな着手：E4を4状態で点検

尺度見直しで主解析内に境界が残ったE4を、まず局所安定性から扱う。
E4では木部炭素Wも水理へ戻るので、E2/E3の3状態へ切り詰めてはいけない。
式の依存関係から、能動変数は \((\psi_x,\psi_l,L,W)\)、
R/Sは受動線形フィルタであり、全Jacobianは

\[
 J=\begin{pmatrix}A_4&0\\B&P_2\end{pmatrix},\qquad
 \det(\lambda I-J)
 =(\lambda+k_R)(\lambda+k_S)\det(\lambda I-A_4).
\]

これは定常近似ではなく厳密なブロック分解である。
4次多項式を
\(\lambda^4+a_1\lambda^3+a_2\lambda^2+a_3\lambda+a_4\) とすると、
正の \(a_i\) に加え、

\[
 \Delta_2=a_1a_2-a_3>0,\qquad
 \Delta_3=a_1a_2a_3-a_3^2-a_1^2a_4>0
\]

でHurwitz安定となる。6状態の特性多項式とこの因数分解の一致も数値検証した。
VPD約0.0026647529 MPaの近くで、他の上記条件が正のまま
\(\Delta_3\) と臨界共役対の実部が符号を変えることを点検した。

- 周辺VPDの幅：±10⁻⁸ MPa、半幅でも再評価。
- \(\Delta_3\)：下側 \(+7.1473\times10^{-8}\)、上側 \(-7.1433\times10^{-8}\)。
- 臨界対の実部のVPD微分：約419.869 day⁻¹/MPa。二つの幅で一致。
- 境界の角周波数：約0.0222194 day⁻¹。線形振動の周期は約283 day。
  **有限振幅の周期解を求めた値ではない。**

最初に±10⁻⁶ MPaで点検したところ、不安定側では既に他のHurwitz条件も失われた。
「境界でどの条件が最初にゼロになるか」を分けて確認するため幅を縮め、
さらに半幅で微分の収束を点検した。微小幅を気象の観測精度だとは解釈しない。

ここまでが次段階の初期点検である。**E4の第一Lyapunov係数、
非退化Hopfの確定、周期解の安定性・大域的回復境界は未実施。**
次は合成係数への感度を点検し、E4の局所非線形解析へ進む。
死亡・再生・領域退出後の生理を追加する場合は、別途利用者と定義を相談する。
