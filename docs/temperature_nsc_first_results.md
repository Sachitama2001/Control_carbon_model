# 温度–NSCモデル：第一段階の結果と次の判断

2026-09-22。対象：`temperature_nsc_r_tipping_research_plan.md`。
式・単位・全パラメータ・出典は [定義書](temperature_nsc_equations.md)、
数理的な議論は [日本語TeX](temperature_nsc_first_results.tex) にまとめた。

## 結論

**今回実行した温度経路ではR-tippingを検出しなかった。**
ただし、この8状態モデルでの一般的な不存在証明ではない。

1. 器官別収支を8状態の連続時間モデルとして実装した。標準の一定目標葉量モデルは、
   7温度×6初期条件の42本すべてが各温度の同じ正の平衡へ収束した。
2. 目標葉量を幹・根の量へ依存させた比較モデルでは、正の安定平衡、鞍点、安定な無植生境界が共存した。
   約37.50696℃にfoldがあり、これは**B-tippingの構造**である。未較正なので現実の枯死温度を意味しない。
3. 多安定性があっても、今回の昇温速度族は別の吸引域へ移らなかった。
   fold近傍で500年後に残った偏差は、2000年保持すると解消する長い過渡応答だった。
4. 比較モデルの多安定性はNSC依存枯死を除いても残った。
   「NSC枯死閾値によるR-tippingの発見」と報告してはならない。

水分モデルと既存結果は変更せず、独立の `artifacts/temperature_nsc/` 以下に保存した。

## 数理的に分かったこと

### 枯死関数だけでは濃度は下がらない

BとSに同じ死亡率μが作用するなら、χ=S/(B+S)の微分からμは相殺される。
濃度低下の増幅は、枯死→葉量→光合成→NSCという間接経路で実際に生じる必要がある。

### 単純な2状態系での不成立条件

固定葉割合、共通turnover、成長投資kSという追加仮定を持つ補助系では、正の平衡濃度は
`y k χ/(1−χ) = μ(χ)+τ`から一意に決まる。左辺は増加、右辺は減少するためである。
その濃度を代入したバイオマス平衡式は狭義減少関数のゼロ点で、正の平衡は高々1個。
正のfoldはない。さらにdivergenceは`−k−2(μ+τ)−r B K/(K+S)²<0`となり、
Bendixsonの判定で内部周期軌道を排除できる。正の平衡はdet>0、trace<0で局所安定。
この証明を追加の器官配分・展葉制約を持つ8状態系へそのまま拡張してはならない。

### 葉の再建則の次数が無植生近傍の安定性を変える

一定目標では微小植生からの葉再建がO(ε)、支持組織依存ではO(ε²)となる。
後者は微小状態で葉再建が損失に負ける仕組みを追加している。
標準モデルの微小植生侵入指数は、10–40℃の試験点で0.00263–0.0131 day⁻¹と正だった。
原点のχ=0/0に通常のヤコビアンを当てたのではなく、同次一次極限から計算した。

支持組織依存の20℃の正の安定平衡はB=80.770、鞍点はB=0.042814 Mg C ha⁻¹。
NSC依存枯死を除くと、それぞれB=129.041、0.038625で、二つの正の根は残る。
今回の多安定性を枯死閾値だけに帰すことはできない。

### foldの数値的確認

比較モデルのfoldはT=37.50696177℃、B=0.733562 Mg C ha⁻¹。
F=0と零固有値条件を同時に解き、物理単位の最大収支残差は4.70×10⁻¹⁷。
log座標ヤコビアンの零特異値は1本で、左零ベクトルw、右零ベクトルvに対して
wᵀF_T≈−0.03756、wᵀD²F[v,v]≈−0.005320と非零だった。
符号はベクトルの向きに依存するが、非零性は通常のfold条件と整合する。
区間演算による厳密証明ではない。

## 過程除去とその限界

標準モデルの25℃で、葉量依存GPPの除去、高温GPP低下の除去、Q10=1、NSC枯死の除去は
正の平衡へ収束。展葉経路全体の除去は無植生近傍へ接近、転流なしは数値領域限界で停止した。
展葉のNSC支払いだけをなくして葉成長を残すと収支を破るため、実施していない。
経路全体の除去はコストだけの効果を同定する対照ではない。
葉量依存GPPの除去も無植生に光合成を与えるため、生態学的候補ではなく機構診断に限る。

## 次の方向性

新しい状態を追加する前に、二つの構成式を文献・観測で拘束したい。

1. **目標葉量・再建能力**：一定目標と支持組織依存のどちらが対象とする均質植生に適切か。
   支持組織依存だけで多安定性を作れるため、この仮定の根拠が最優先。
2. **呼吸制限の基準**：N_i/(K_i+N_i)は面積当たり絶対NSCで制限する。
   濃度を保って植生量だけを縮小しても単位構造炭素あたり支払い呼吸がゼロへ近づくため、
   濃度基準の制限との比較が必要。これは現行式の性質からの提案で、文献同定済みの改良ではない。

現行標準モデルの20℃平衡では全植物χ≈0.1404。器官濃度も観測照合しておらず、
この領域を生態学的に妥当とは呼べない。状態数や死亡係数を調整してR-tippingを作るのではなく、
定義とパラメータの裏付けを先に進める。その後に経路と吸引域の幾何を調べ、必要なら
被覆・損傷・順化状態の追加gateへ進む。

既存のcapacity=QSEという議論への接続では、比較モデルのように複数の吸引状態があれば、
まずどのQSE枝をcapacityと呼ぶか指定する必要がある。ただし、今回は初期値依存の多安定性を
確認したのであって、速度変化が正のQSEから別の吸引域へ状態を移した証拠ではない。
状態依存係数を現在値で固定した行列capacityと、非線形全体系のQSEも同一視しない。
