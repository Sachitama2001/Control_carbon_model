# 10プール炭素収支：解析用候補

2026-09-30。分類：**model-agnostic derived analysis**。
[過程台帳](tree_grass_process_ledger.md)に記した構造的仮定に基づく。
native VISIT、SPITFIREの転記、較正されたCerradoモデルではない。

## 1. 状態と入力

x=(L_T,S_T,R_T,D_T,H_T,L_G,S_G,R_G,D_G,H_G)ᵀ。
全量kg C m⁻²、時間yr、i∈{T,G}、j∈{L,S,R}、C_ijは生体各部位。
Dはリターを含む統合枯死物、Hはhumus。水の状態は追加していない。

配分p_ij>0、Σ_j p_ij=1は一定。NPP入力を

\[
\mu_T=P_T(m)(1-e^{-a_T L_T}),\qquad
\mu_G=P_G(m)e^{-\kappa L_T}(1-e^{-a_G L_G})
\]

と仮定する。P_i≥0はkg C m⁻² yr⁻¹、a_i>0、κ≥0は炭素面密度の逆数。
m=(T,θ)への応答式は台帳の通り未同定。NPPから既に引かれたRaを再度引かない。
P_iは生理定数ではなく、固定背景条件での有効な非負生産上限。

この入力は葉がゼロならゼロ。種子流入、根から葉への炭素転流、落葉後の展葉を
含まない。**完全落葉からの萌芽を扱えない**ため、topkill後の回復を実証するモデル
としては未完成。解析は正の葉量と連続平均損失の範囲から始める。

## 2. 過程別の収支

通常turnoverをd_ij>0、火災遭遇率をf=λ(m)h(χD_G)、0≤h≤1、h(0)=0とする。
hはC¹、λ≥0、χ∈[0,1]。η_ij∈[0,1]は遭遇当たり損傷率、
b_ij∈[0,1]は損傷炭素のうち燃焼放出される割合。
c_i∈[0,1]はDの遭遇当たり燃焼率。humusの直接燃焼は除外する。

\[
\dot C_{ij}=p_{ij}\mu_i-(d_{ij}+\eta_{ij}f)C_{ij},
\]
\[
\dot D_i=\sum_j[d_{ij}+(1-b_{ij})\eta_{ij}f]C_{ij}
 -(k_D+c_i f)D_i,
\qquad
\dot H_i=\rho k_D D_i-k_H H_i,
\]

k_D,k_H>0（yr⁻¹）、0≤ρ≤1。火災を連続平均化した仮定であり、
離散イベントの発生・燃え広がり・燃焼直後の完全落葉は記述しない。
火災間隔に対する平均化の妥当性は未検証。

行列は各群の5×5ブロック対角で、非零要素を

\[
M_{jj}=-(d_{ij}+\eta_{ij}f),\quad
M_{Dj}=d_{ij}+(1-b_{ij})\eta_{ij}f,
\]
\[
M_{DD}=-(k_D+c_i f),\quad M_{HD}=\rho k_D,\quad M_{HH}=-k_H
\]

とする。Bのi列の生体3行がp_ij、他はゼロ。
Mがブロック対角でもfがD_Gに依存するので、全ヤコビアンは群間結合を持つ。
各過程を別々のA_p K_p（Ξ_pへf等を含めてもよい）に分けて表せる。
枯死を大気放出と誤認しないため、この過程区分をcapacity計算でも固定する。

## 3. 非負性・予算・有界性

各状態がゼロの面では、その微分は非負。局所Lipschitzな係数の下で
非負直交象限は前方不変。正の葉は
L_i(t)≥L_i(0)exp(−∫(d_iL+η_iL f)dt)>0
なので、有界率の有限時間強制ではゼロに到達しない。

\[
R_h=\sum_i[(1-\rho)k_D D_i+k_H H_i],
\]
\[
E_{fire}=f\sum_i\left[\sum_j b_{ij}\eta_{ij}C_{ij}+c_iD_i\right],
\quad
\dot X=\mu_T+\mu_G-R_h-E_{fire}.
\]

内部移動は相殺される。NEP=NPP−Rh、dX/dt=NEP−E_fire。
搬出ゼロ。燃焼は炭素の大気への放出として集計し、全量をCO₂と同定しない。
火災損傷の非燃焼分はDへ入り、後の分解で放出される。

係数を固定、または時間変化する係数に共通の有限上限・正の損失下限がある場合、
μ_i≤P̄_iより各C_ijは線形比較で有界。
f≤λ̄だからDへの流入も有界、k_D≥k̲_D>0よりDが有界。
最後にk_H≥k̲_H>0よりHも有界。よって有限初期状態から大域解が存在する。
損失下限ゼロの極限について有界性を自動的に主張しない。

## 4. 土壌集約の限界

c_T=c_G=cで共通k_D,k_H,ρなら、D=D_T+D_G、H=H_T+H_Gは

\[
\dot D=\sum_{ij}[d_{ij}+(1-b_{ij})\eta_{ij}f]C_{ij}-(k_D+cf)D,
\quad\dot H=\rho k_D D-k_H H
\]

を厳密に満たす。ただし、fがD_Gを見るならDだけでは系が閉じない。
**集約収支が正しいことと、由来情報を捨てて動態が閉じることは別**。
火災を除き、生体への他の土壌フィードバックもない対照では、D,Hだけに集約できる。
H由来分割は同じ率であれば常に集約可能。

## 5. 凍結capacity

各状態でMは三角ブロック、対角は負、したがってHurwitzかつ可逆。
係数・μを現在値に固定すると

\[
C^{cap}_{ij}=\frac{p_{ij}\mu_i}{d_{ij}+\eta_{ij}f},\quad
D^{cap}_i=\frac{\sum_j[d_{ij}+(1-b_{ij})\eta_{ij}f]C^{cap}_{ij}}{k_D+c_i f},
\quad H^{cap}_i=\frac{\rho k_D}{k_H}D^{cap}_i.
\]

これは現在の入力・係数を止めた線形系のcapacity。実装検算では線形方程式を解く。
c_pot=c_cap−x、ẋ=−M c_pot。自己整合平衡と安定性は
[別の解析](tree_grass_bistability_analysis.md)で扱う。

問い：10プール内で閉じた予算と解析可能な相互作用を両立できるか。
仮定：非負NPP、一定配分、平均火災、統合枯死物。
式変形：過程別流量をMと外部フラックスへ分割。
得た命題：非負性、有界性、炭素予算、凍結Mの安定性。
未証明：現地適合性と火災平均化。次の一手：平衡消去と全系安定性。
