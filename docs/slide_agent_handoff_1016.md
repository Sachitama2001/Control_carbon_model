## 数値・式の監査基準

- E0 fold：約 **2.472042553 kPa**。E1 fold：約 **1.546784415 kPa**。
- E4正通水平衡が存在する範囲：`0≤v<4.806749409 kPa`、基準係数。`v=4.806749409 kPa` の `L=0` 端点を**正根に数えない**。
- E4の主範囲Hopf：約 **2.664752905 kPa**、葉L約 **0.048007633 kg C/m²**。subcritical Hopf、近傍の周期軌道は不安定で吸引子ではない。
- E4の約4.791823 kPaの第2固有値横断は25°Cでの飽和を超える**形式的高VPD結果**。その非線形型は未判定。主要発表から省略してよい。
- 炭素平衡で W=21.333333L、R=4L、S=54L、今回の基準係数限定。
- unsafe conductance閉鎖：xylem ψ≤−3 MPa、stomata ψ≤−4 MPa。木部閉鎖だけでは瞬間GPPとKがゼロになるとは限らない。
- 木部閉鎖領域での葉量減衰評価：`L(t)≤L0 exp(−σt)`、`σ=0.35/year`（今回の係数）。E4では `gs(∞)>0` でも `L,K,C→0` が可能。これは**形式的なODE極限**であり、実装された死亡レジームではない。
- 固定VPD 2.44 kPaの数値例：E0/E4、初期ψleaf−1.5で100年後に正平衡近傍、−2.5で約14.146/14.493年に退出、−4.2で約14.145/14.490年に退出。−3.5かつ極小Lでは約0.867/1.204年に退出。**表示する全状態初期値ベクトルは必ず既存JSONまたは再計算から抽出し、推測しない**。

## 追加でエージェントに求める「再解釈」

以下は再解釈の**言葉の整理**であって、数値結果の上乗せではない。

1. **capacity自体は消えたのか？** → 定義式Kは有効のまま。環境・植物状態によりKの値がゼロになる、または正の自己整合的capacity候補が消失する場合がある。この二つは区別。
2. **複数capacityとは何か？** → 同一固定VPDで `C=K(y,v)` と水理平衡を同時に満たす複数解。瞬間capacity写像が二値になるという意味ではない。
3. **一意なら追従可能か？** → いいえ。E4では一意正根でもHopfを通して不安定になる。初期状態がbasinにない場合もある。
4. **hydraulic failureは死亡なのか？** → この研究のManzoni系では低通水不変領域や炭素衰退の数学的挙動であって、検証済みの死亡・再生生理ではない。
5. **研究の価値は何か？** → 既知の炭素・水モデルを結合したことではなく、**非線形capacityを長期貯留予測として解釈するための条件を、代数的存在分類、全結合安定性、水理閉鎖の不変性の三層に分けたこと**。一般の新規性の主張には文献比較が必要。
